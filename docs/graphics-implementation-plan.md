# Implementation Plan: Dual-Camera 3D RPG Graphics & Streaming Architecture

This document defines the phased implementation plan for realizing [Architectural Design Specifications for a Dual-Camera 3D RPG Graphics Engine](graphics-architecture.md) inside Dragon Engine while preserving all runtime invariants in [Engine Architecture Principles](engine-architecture.md). Post-baseline virtual geometry upgrades (Tier 2 Visibility Buffer + hybrid HW/SW rasterizer and Tier 3 programmable/skinned/cluster-RT virtual geometry) are specified separately in [Future Graphics Architecture Plans](graphics-future-plans.md).

---

## 1. Locked Architectural Decisions

These decisions are final and must not be reopened during implementation without an explicit Blueprint review:

1. **Strict Vulkan 1.4 Minimum Hardware via Private `ash 0.38` + `gpu-allocator 0.28` (Upgrade to `ash 0.39` on Release):** Target native **Vulkan 1.4** ray-tracing hardware exclusively (Linux including Steam Deck, and Windows) through private `ash 0.38`, `ash-window 0.13`, and pure-Rust `gpu-allocator 0.28` inside `crates/engine/src/gpu/`. Startup sets `ApplicationInfo::api_version = vk::make_api_version(0, 1, 4, 0)`, strictly requires a conformant Vulkan 1.4 ray-tracing adapter (`props.api_version >= vk::make_api_version(0, 1, 4, 0)`; zero sub-1.4 or software-rasterizer fallback), checks `vkEnumerateDeviceExtensionProperties` (strictly requiring `VK_KHR_push_descriptor` to be advertised under `ash 0.38` because `ash 0.38` lacks the unsuffixed core 1.4 `vkCmdPushDescriptorSet` loader) before enabling suffixed `ash 0.38` KHR/EXT extension loaders actually consumed (`VK_KHR_push_descriptor`, mandatory Vulkan 1.4 `VK_KHR_index_type_uint8`, optional `VK_EXT_host_image_copy`) in `vkCreateDevice::ppEnabledExtensionNames` until `ash 0.39` + matching `gpu-allocator` release on crates.io. Native macOS, DX12, Metal, WebAssembly, and `wgpu` are out of scope. Zero raw Vulkan handles are exposed outside `crates/engine`.
2. **Strict 100% `rust-gpu` Vulkan 1.4 SPIR-V with Modular Stage-Grouped Crates (Zero WGSL, Zero Shader Cross-Compilers):** All engine-authored and game-authored compute, mesh, ray-query, graphics, upscaling (`TaauRcas`), and declarative `RenderEffect` shaders live in modular `rust-gpu` crates (top-level `crates/shader_common` shared `#![no_std]` library with `crate-type = ["rlib"]`, never `dylib`, alongside `crates/shader_abi` so both engine shader crates and external `RenderEffect` workspaces share helpers cleanly + 4 stage-grouped `dylib` crates under `crates/engine/shaders/`: `core_shader_geometry`, `core_shader_raytracing`, `core_shader_shading`, and compile-time-isolated `core_shader_mesh`, alongside external crates such as `crates/fx_fresnel_rim`) compiled with `spirv-builder 0.11.0` (`spirv-unknown-vulkan1.4`, one shared `target_dir_path` using a 2-tuple capability split so `core_shader_geometry`, `core_shader_shading`, and `core_shader_raytracing` share one base RT capability/extension set while only `core_shader_mesh` adds `MeshShadingEXT`, compiling `-Zbuild-std=core` twice on clean builds rather than 4 times, `SpirvBuilder::multimodule(true)` with `env_shader_spv_path = Some(false)`, `.scalar_block_layout(true)`, `.release(false)` + `SpirvMetadata::NameVariables` in debug builds to skip `spirv-opt` cleanly without warnings while keeping `spirv-val` enabled, plus a per-crate `.release(true)` fallback if `spirv-val` rejects un-legalized debug SPIR-V on complex `RayQuery`/`RuntimeArray`/`workgroup` loops or if unoptimized debug `core_shader_raytracing` frame times become impractical, and one unified `OUT_DIR` module manifest) and loaded directly via `vkCreateShaderModule`. Shaders standardize on the frozen external `crates/shader_abi` 2-set + inter-stage ABI (while internal engine-only pass structs remain additive across Phases 2 to 6b): **Set 0** (`SET_BINDLESS_GLOBAL = 0`, triple-buffered `[vk::DescriptorSet; 3]` across 3 frames in flight so per-frame UBO/material/instance/light updates never violate `VUID-vkUpdateDescriptorSets-None-03047`, ordered so the variable-count bindless array is the highest binding per `VUID-VkDescriptorSetLayoutBindingFlagsCreateInfo-pBindingFlags-03004`: `b0` per-frame `FrameConstants` UBO, `b1` frozen `SAMPLER_COUNT = 5` immutable samplers, `b2..b13` persistent and per-frame-slot scene SSBOs including triple-buffered `b2` `GpuMaterial`, `GpuSubmeshDesc`, static geometry/meshlet arenas, actor-local rotating 3-slice skinned vertex ring `b8`, per-frame `GpuInstance` `b9` with `active_lod`, per-frame `GpuLight` `b10`, clusters, and world light grid, `b14` unsized `RuntimeArray` sampled images using fresh-slot `S_new` swap across all 3 Set 0 instances so in-flight frames never read an overwritten slot; `UiPipeline` keeps its own private descriptor layout) + **Set 1** (`SET_PASS_TRANSIENT = 1`, `pushDescriptor` for per-pass transients, frozen Pass-8/10/11 `RenderEffect` inputs, and Pass 7 TLAS, verified `maxPushDescriptors >= 32`) + push-constant pool discriminators/element offsets (no shader-side `PhysicalStorageBuffer` pointers, keeping host-side BDA strictly for Vulkan AS builds) + frozen Pass-8 fragment-only inter-stage locations (`location 0..5`: `world_pos`, `world_normal`, `world_tangent`, `uv`, `flat instance_index`, `flat material_id`). All runtime crates (`engine` runtime, `shader_abi`, `fx_fresnel_rim`, `game`) compile strictly with pure-Rust dependencies; offline build tooling (`spirv-builder`'s `spirv-tools-sys`, plus an optional offline-only carve-out in `crates/asset_pipeline` if Phase 0a's crate smoke check identifies missing skinned simplification or prohibitive CPU BC7 release bake times) stays isolated from runtime crates.
3. **Scoped `unsafe` Isolation & Real-HW Vulkan 1.4 Validation:** Keep `unsafe_code = "deny"` in root `Cargo.toml` across all public APIs, simulation, gameplay, `shader_abi`, `asset_pipeline`, and host `fx_fresnel_rim`. Isolate host `#[allow(unsafe_code)]` strictly inside two private audited boundaries with explicit `// SAFETY:` comments and mandatory `VK_LAYER_KHRONOS_validation` testing directly on real Vulkan 1.4 ray-tracing hardware:
   - `crates/engine/src/gpu/` (private Vulkan 1.4 `ash` + `gpu-allocator` backend), and
   - `crates/engine/src/assets/mmap_store.rs` (read-only immutable `mmap` slices via `memmap2` with an explicit immutable-archive safety contract).
   Isolated `#![no_std]` shader crates (`crates/shader_common` and `crates/engine/shaders/core_shader_*`, excluded from the root workspace) invoke `unsafe` `spirv-std 0.11.0` hardware intrinsics (`RuntimeArray::index`, `RayQuery::*`, `Image::write`, `set_mesh_outputs_ext`, `emit_mesh_tasks_ext`), wrapped via `crates/shader_common` helpers where appropriate.
4. **Zero-Loading-Screen Async Pop-In (Frame-Pacing First):** Never stall simulation or rendering on disk I/O, decompression, GPU upload, BLAS build/compaction, or physics splicing. Accept visible asynchronous pop-in over frame-rate stutter.
5. **Independent Per-Subsystem Residency Policies, Type-Split `GpuPoolConfig` / `RuntimeGraphicsSettings` & Hard Physical Safety Clamping:** Physics, Geometry/LOD, Ray-Tracing BLAS, Actors/AI, and GPU-Feedback Mipmap Streaming each own independent spatial residency policies and scaling parameters (no coupled monolithic sector rings). Configuration partitions at the type level into startup-immutable **`GpuPoolConfig`** (pool capacities and spatial residency ceilings passed once via `EngineConfig`) and hot-swappable **`RuntimeGraphicsSettings`** (mutable per frame via `EngineContext` / `RenderSnapshot`), both initialized from one shared `QualityPreset` (`Low` / `Medium` / `High` / `Ultra`); the Runtime Hardware Scaling Matrix in `docs/graphics-architecture.md` is purely informative and the engine never blindly detects GPU model names to override settings. At startup, the engine applies only hard physical safety clamping against Vulkan device limits and `VK_EXT_memory_budget` (`<= 75%` of available `DEVICE_LOCAL` heap budget, reserving fixed targets/pools + `BLAS_POOL_BUDGET_MB` first, then splitting remaining headroom `25%` static geometry / `75%` texture streaming up to configured `GpuPoolConfig` ceilings).
6. **Lightweight Streaming Pacing (No Runtime Millisecond Timers):** Use only a fixed-size Pass 1 staging ring (`STAGING_RING_MB` per-frame slice in `GpuPoolConfig`, `3 * STAGING_RING_MB` total host-visible ring, optionally supplemented by Vulkan 1.4 `hostImageCopy` for small mip tails and UI RGBA8), `RuntimeGraphicsSettings`-configured per-frame static BLAS build count and triangle caps (`STATIC_BLAS_BUILDS_PER_FRAME`, `STATIC_BLAS_TRIS_PER_FRAME`), and `VK_EXT_memory_budget`-clamped VRAM budgets (`STATIC_GEOMETRY_ARENA_MB`, `BLAS_POOL_BUDGET_MB`, `TEXTURE_STREAM_BUDGET_MB`). Millisecond figures are design-time references and offline QA profiler targets, never runtime timers.
7. **Zero-Lag Pass 2a / Pass 2b / Pass 3 Ordering, Dual-Style Direct Lighting & 11-Pass Unified Viewmodel Pipeline:** Execute **Pass 2a (Compute Meshlet Skinning)** before **Pass 3 (In-Place Dynamic BLAS Refit, Async Static BLAS Compaction, and Active-Radius TLAS Rebuild)** and **Pass 4 (World Thin Prepass)** so rasterization, ray queries, and lighting read identical Frame N poses, while running **Pass 2b (Dynamic TOD Sky LUT / Amortized IBL Compute)** asynchronously ahead of **Pass 7 (Realistic Demodulated ReSTIR DI with NRD-style `EnvBRDF` remodulation / Comic Deterministic Sun + Top-3 Priority-Sorted Cluster-Light `R8G8B8A8_UNORM` Visibility Mask, Reflections, Radiance Cascades)** (overlappable with Pass 4/5 via whole-image QFOT) so Passes 7, 8, 9, and 10 read identical Frame N sky/IBL state. Partition first-person reverse-Z viewports strictly into `[0.0, 0.95]` (world across Pass 4/5 and Pass 11 highlights, with world Hi-Z tests scaling `z_ndc` by `0.95`) and `[0.95, 1.0]` (capsule-scaled `0.15x-0.20x` viewmodel around the camera eye with matching near/far planes drawn at the end of Pass 5 after the finalized half-res world Hi-Z update and single-phase transparent cull, packing 1-bit `is_viewmodel` into `R8_UINT`, excluded from both Hi-Z and TLAS) so weapons receive full ReSTIR DI, reflections, and GI with zero wall clipping, zero wall-penetration lighting inversion in Pass 7 TLAS ray queries, and zero Hi-Z contamination in an **11-pass** Render Graph.
8. **Zero Runtime PSO Stutter & Wave-Portable Subgroups:** Precompile all fixed bindless compute, mesh, and graphics pipelines (including registered `RenderEffect` pipelines) once at startup backed by `VkPipelineCache`. Write all subgroup compute shaders wave-size-agnostic (`#[spirv(subgroup_size)]`, 128-bit `SubgroupMask`) with an opt-in Wave32 pipeline hint (`subgroupSizeControl`, `requiredSubgroupSize = 32` when supported by the adapter).
9. **Optional/Auto Tier-1 Cluster-DAG Virtual Geometry with Zero-Cost Bypass (Scheduled in Dedicated Phase 6b):** Support crack-free Cluster-Group DAG continuous LOD and `128 KB` quantized cluster page streaming under configurable `VirtualGeometryMode` (`Disabled` | `Auto` default with `VG_MIN_TRIANGLES = 2,048` | `Always`) strictly for qualifying static opaque meshes (excluding `cutout_eligible` walls, `highlight_eligible` interactive actors, and meshes with `EffectAttachment`), feeding the identical Pass 4/5 Thin Prepass and Pass 8 Clustered Forward shading pipeline via a dedicated Set-1-bound VG draw queue (zero changes to Set 0 `b0..b14` or Pass 8 `RenderEffect` fragment ABI). Phase 0b reserves the external VG ABI slots and `GpuPoolConfig`/`RuntimeGraphicsSettings` knobs so the core 11-pass flat-meshlet renderer completes through Phase 6 first, and Phase 6b implements the offline DAG builder, lazy page streamer, GPU Cluster-BVH traversal, and coarse RT proxy hookup with zero ABI rework. Scenes with zero VG assets (`vg_instance_count == 0`) or `virtual_geometry_enabled = false` incur `0.0 MB` VG VRAM and `0.00 ms` GPU overhead. Static VG meshes supply pre-baked coarse RT fallback proxies to Section 9 `BlasPool`.

## 2. Baseline Codebase Readiness Audit

Before Phase 0 expansion, the workspace (`ash 0.38`, `ash-window 0.13`, `gpu-allocator 0.28`, `spirv-builder 0.11.0`, `spirv-std 0.11.0`, `glam 0.34.1`, `rapier3d 0.36.1`, `winit 0.30.13`, Rust edition `2024`) has these completed foundations and remaining structural gaps:

### Ready Foundations
- **Private Vulkan 1.3 Baseline (`crates/engine/src/gpu/`):** `ash 0.38` + `ash-window 0.13` + `gpu-allocator 0.28` device/swapchain/dynamic-rendering/`synchronization2` renderer, `spirv-unknown-vulkan1.3` shader builds, `EngineError::Gpu` typed startup errors, declarative `RenderEffect` (`EffectShaderSpec`, zero `ash`/`unsafe` in `crates/fx_fresnel_rim`), private `UiRenderTarget::composite_rgba8`, and headless Vulkan 1.3 SPIR-V pipeline validation tests.
- **Simulation/Render Isolation (`crates/engine/src/runner.rs`, `snapshot.rs`):** `Renderer` is private and reads immutable double-buffered `RenderSnapshot<G>`. `RenderSchedule::Parallel` overlaps `Sim N+1` with `Render N`.
- **Shared ABI (`crates/shader_abi/src/lib.rs`):** `#![no_std]` crate with scalar-backed `#[repr(C)]` types (`Vec4f`, `Mat4f`) and optional `bytemuck` derives shared by `engine` and `core_shader`.
- **Contiguous Transform Storage (`crates/engine/src/physics.rs`):** `SoaStorage` maintains dense `positions`, `rotations`, and `bounds` arrays.
- **Decoupled UI (`crates/engine/src/ui.rs`):** `UiOverlay::render` runs after the 3D scene pass via `UiRenderTarget::composite_rgba8`.

### Structural Gaps Addressed by Phases 0 to 3
1. **Immediate-Mode Box Snapshot vs. Retained GPU Scene (`world.rs`, `gpu/scene_pipeline.rs`, `runner.rs`):** `collect_render_meshes` performs a hardcoded 200 m CPU octree query and clones box primitives every frame. Must transition to a retained GPU scene fed by a frame-index-fenced append-only monotonic delta queue (`delta.frame_index <= snapshot.frame_index`, accumulating mutations across `Sim` steps so `Parallel -> Sequential` overwrites and pre-`resumed` `GameApp::init` spawns never drop updates and `Sim N+1` never leaks into `Render N`) plus per-frame dynamic state (previous-frame transforms for motion vectors and `history_reset` invalidation flags).
2. **Missing Asset Registry & Upload Queue (`runner.rs`, `world.rs`):** `SimRunner::new` runs `GameApp::init` before `VulkanDevice` exists. Requires a device-independent opaque handle registry bridged to an async GPU upload queue.
3. **Strict Vulkan 1.4 Minimum Upgrade, Frame-Sync Migration & Render Graph (`gpu/device.rs`, `gpu/renderer.rs`, `gpu/scene_pipeline.rs`, `gpu/ui_pipeline.rs`):** The completed baseline currently checks `API_VERSION_1_3` with `FRAMES_IN_FLIGHT = 2` (shared across `renderer.rs`, `scene_pipeline.rs`, and `ui_pipeline.rs`) and binary `vk::Fence`. Phase 0a upgrades startup to enforce **strict Vulkan 1.4 minimum** (`ApplicationInfo::api_version = 1.4.0`, `props.api_version >= 1.4.0`, rejecting any sub-1.4 or non-RT adapter), compiles engine and `fx_fresnel_rim` shaders to `spirv-unknown-vulkan1.4` (splitting `core_shader` into top-level `crates/shader_common` + 4 stage-grouped crates), enables exact Vulkan feature structs (Vulkan 1.0 `VkPhysicalDeviceFeatures`: `multi_draw_indirect`, `draw_indirect_first_instance`, `sampler_anisotropy`, `shader_sampled_image_array_dynamic_indexing`, `fragment_stores_and_atomics`, `shader_storage_image_extended_formats`, `shader_storage_image_write_without_format`, `depth_clamp`; read-only compute inputs use `SAMPLED_IMAGE` fetch so `shader_storage_image_read_without_format` is not required, and `b12`/`b13` pack two `u16` light IDs per `u32` word so neither `shader_int16` nor `storage_buffer16_bit_access` is required; `PhysicalDeviceVulkan12Features`: `timeline_semaphore`, `buffer_device_address`, `draw_indirect_count`, `scalar_block_layout`, `runtime_descriptor_array`, `descriptor_binding_partially_bound`, `descriptor_binding_sampled_image_update_after_bind`, `descriptor_binding_variable_descriptor_count`, `shader_sampled_image_array_non_uniform_indexing`; `PhysicalDeviceVulkan13Features`: `dynamic_rendering`, `synchronization2`, `subgroup_size_control`, `compute_full_subgroups`; `PhysicalDeviceRayQueryFeaturesKHR`; `PhysicalDeviceAccelerationStructureFeaturesKHR`; mandatory Vulkan 1.4 `PhysicalDeviceIndexTypeUint8FeaturesKHR`; optional `PhysicalDeviceMeshShaderFeaturesEXT` (gated on `maxMeshOutputVertices >= 64 && maxMeshOutputPrimitives >= 124 && maxMeshWorkGroupInvocations >= 64`) / `PhysicalDeviceHostImageCopyFeaturesEXT`; plus `VkPhysicalDeviceSubgroupProperties`, `requiredSubgroupSizeStages`, and `PhysicalDevicePushDescriptorPropertiesKHR::max_push_descriptors >= 32` verification) and enables only the advertised device extensions actually consumed (strictly requiring `VK_KHR_push_descriptor` advertisement under `ash 0.38`, plus `VK_KHR_index_type_uint8`, `VK_KHR_ray_query`, `VK_KHR_acceleration_structure`, `VK_KHR_deferred_host_operations`, `VK_EXT_memory_budget`, `VK_KHR_swapchain`, optional `VK_EXT_mesh_shader`, and optional `VK_EXT_host_image_copy`). Phase 0b then migrates `VulkanRenderer` and `UiPipeline` to triple-buffered dynamic pools + timeline-semaphore submit-serial reclamation (`completed_timeline_value >= freed_at_submit_serial`) + cross-frame GPU-to-GPU timeline dependencies for single-buffered async-queue resources, adds optional DMA transfer/async compute queues with hybrid cross-queue sync (`CONCURRENT` buffers, `EXCLUSIVE` + whole-image QFOT for images), `VkPipelineCache`, private transient alias `vk::DeviceMemory` heaps, resize/style-switch/device-lost lifecycle handling, and the internal Render Graph barrier tracker.
4. **Missing Rendering Domain Primitives (`physics.rs`, `snapshot.rs`, `save.rs`, `world.rs`, `effect.rs`):** Needs stable persistent `AssetId` and `EffectKey` (`&'static str`) keys vs. ephemeral runtime handles (`MeshHandle`, `MaterialHandle`, `TextureHandle`, `SkeletonHandle`, `FontHandle`, `EffectId`), dynamic lights (`LightId` handle table / commands), highlight categories, cutout flags, dual `CameraMode` (First-Person + viewmodel vs. Isometric + cutout target), `VisualStyle`, `UpscalerBackend`, 3D MSDF signs, and `AssetId` + `EffectKey` + animation-state `ActorCheckpoint` schemas.
5. **GPU-Driven Multi-Stage `RenderEffect` Evolution (`effect.rs`, `crates/shader_abi`, `crates/fx_fresnel_rim`):** `RenderEffect` is already declarative (`EffectShaderSpec`), currently wired to CPU box vertex ranges, ephemeral `EffectId(u32)` checkpoints, and legacy Set 0/Set 1 constants. Phase 0b/3 adds stable `EffectKey` (`&'static str`), migrates `crates/shader_abi` to the frozen external Set 0 (triple-buffered `[vk::DescriptorSet; 3]`, per-frame `FrameConstants`, 5 immutable samplers, triple-buffered `b2` `GpuMaterial`, fixed-handle scene SSBOs, highest-binding bindless `RuntimeArray`) / Set 1 (`pushDescriptor` per-stage transient bindings) / Push-Constant / Pass-8 inter-stage `location 0..5` (including `flat material_id: u32`) ABI, and evolves `EffectShaderSpec` to typed Pass-8 fragment-only hooks (overlay vs. opaque replacement reusing engine `#[spirv(invariant)]` prepass front-ends with `CULL_MODE_BACK` and `CULL_MODE_NONE` variants), Pass-10 transparent hooks (`TransparentHookLayer::PreStandard` / `PostStandard` default per-`EffectId` sorted indirect batches with optional custom vertex entry points and separately isolated `MeshEXT` fallback pairs for non-mesh GPUs), and Pass-11 fragment-only fullscreen-triangle post hooks (extensible non-breakingly via an additive Set 1 `b5` `STORAGE_IMAGE` output if compute post hooks are ever needed) backed by per-`EffectId` indirect/mesh queues emitted by Pass 4/5 and GPU instance `EffectAttachment` parameters.
6. **Full-World `Octree::rebuild` (`physics.rs`):** Rebuilds the entire octree on every spawn, despawn, or `SetPosition`. Must separate versioned pre-baked static sector colliders from Rapier's incremental dynamic broadphase.
7. **Large-World Precision (`physics.rs`, `snapshot.rs`, `world.rs`, `save.rs`):** `rapier3d` and `glam::Vec3` use `f32`. Seamless large worlds require canonical `DVec3` across `ActorSpawnDesc`, `PhysicsCommand`, `WorldReadView`, `SpatialQuery`, `Aabb3`, `RaycastHit`, `CameraSnapshot`, `GizmoBox`, and `ActorCheckpoint`, with active-origin rebasing for `rapier3d` and camera-relative `f32` rebasing in Pass 1.

## 4. Phased Implementation Plan

### Phase 0a: Strict Vulkan 1.4 Device Probing, `rust-gpu` Multi-Module Capability Spike & Phase 1 Crate Smoke Check
- **Spec Sections:** 1, 7, 18.
- **Dependencies:** None (builds directly on the completed `ash` + `gpu-allocator` baseline; fails fast on the two highest external unknowns before building Render Graph and GPU arena infrastructure).
- **Deliverables:**
  1. **Strict Vulkan 1.4 Device Enablement & Format Probing (`crates/engine/src/gpu/device.rs`):**
     - Set `ApplicationInfo::api_version = vk::make_api_version(0, 1, 4, 0)` and enforce **strict Vulkan 1.4 RT minimum** (`props.api_version >= vk::make_api_version(0, 1, 4, 0)`, rejecting any adapter below Vulkan 1.4 or missing RT with `EngineError::Gpu(GpuError::UnsupportedAdapter)`) in both `new_windowed()` and single mandatory-RT `new_headless()` (zero sub-1.4 or software-rasterizer fallback). Enable exact Vulkan feature structs: Vulkan 1.0 `VkPhysicalDeviceFeatures` (`multi_draw_indirect`, `draw_indirect_first_instance`, `sampler_anisotropy`, `shader_sampled_image_array_dynamic_indexing`, `fragment_stores_and_atomics`, `shader_storage_image_extended_formats`, `shader_storage_image_write_without_format`, `depth_clamp`), `PhysicalDeviceVulkan12Features` (`timeline_semaphore`, `buffer_device_address` for host-side AS builds, `draw_indirect_count`, `scalar_block_layout`, `runtime_descriptor_array`, `descriptor_binding_partially_bound`, `descriptor_binding_sampled_image_update_after_bind`, `descriptor_binding_variable_descriptor_count`, `shader_sampled_image_array_non_uniform_indexing`), `PhysicalDeviceVulkan13Features` (`dynamic_rendering`, `synchronization2`, `subgroup_size_control`, `compute_full_subgroups`), `PhysicalDeviceRayQueryFeaturesKHR` (`ray_query`), `PhysicalDeviceAccelerationStructureFeaturesKHR` (`acceleration_structure`, verifying `minAccelerationStructureScratchOffsetAlignment` and enforcing 256-byte `VkAccelerationStructureKHR` sub-allocation alignment per `VUID-VkAccelerationStructureCreateInfoKHR-offset-03734`), mandatory Vulkan 1.4 `PhysicalDeviceIndexTypeUint8FeaturesKHR` (`index_type_uint8`, guaranteed by Vulkan 1.4 core so offline `u8` `meshlet_triangles` buffers bind directly as `VK_INDEX_TYPE_UINT8`), optional `PhysicalDeviceMeshShaderFeaturesEXT` (`task_shader`, `mesh_shader`, gated on `VkPhysicalDeviceMeshShaderPropertiesEXT` verifying `maxMeshOutputVertices >= 64 && maxMeshOutputPrimitives >= 124 && maxMeshWorkGroupInvocations >= 64`), optional `PhysicalDeviceHostImageCopyFeaturesEXT` (`host_image_copy`, querying `VkPhysicalDeviceHostImageCopyPropertiesEXT::pCopyDstLayouts`, creating target images with `VK_IMAGE_USAGE_HOST_TRANSFER_BIT_EXT`, and invoking `vkTransitionImageLayoutEXT` before
