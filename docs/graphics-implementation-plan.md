# Implementation Plan: Dual-Camera 3D RPG Graphics & Streaming Architecture

This document defines the phased implementation plan for realizing [Architectural Design Specifications for a Dual-Camera 3D RPG Graphics Engine](graphics-architecture.md) inside Dragon Engine while preserving all runtime invariants in [Engine Architecture Principles](engine-architecture.md).

---

## 1. Locked Architectural Decisions

These decisions are final and must not be reopened during implementation without an explicit Blueprint review:

1. **Strict Vulkan 1.4 Minimum Hardware via Private `ash 0.38` + `gpu-allocator 0.28` (Upgrade to `ash 0.39` on Release):** Target native **Vulkan 1.4** ray-tracing hardware exclusively (Linux including Steam Deck, and Windows) through private `ash 0.38`, `ash-window 0.13`, and pure-Rust `gpu-allocator 0.28` inside `crates/engine/src/gpu/`. Startup sets `ApplicationInfo::api_version = vk::make_api_version(0, 1, 4, 0)`, strictly requires a conformant Vulkan 1.4 ray-tracing adapter (`props.api_version >= vk::make_api_version(0, 1, 4, 0)`; zero sub-1.4 or software-rasterizer fallback), and explicitly enables only the `ash 0.38` KHR/EXT extension loaders actually consumed (`VK_KHR_push_descriptor`, optional `VK_EXT_host_image_copy`) in `vkCreateDevice::ppEnabledExtensionNames` until `ash 0.39` + matching `gpu-allocator` release on crates.io. Native macOS, DX12, Metal, WebAssembly, and `wgpu` are out of scope. Zero raw Vulkan handles are exposed outside `crates/engine`.
2. **Strict 100% `rust-gpu` Vulkan 1.4 SPIR-V with Modular Stage-Grouped Crates (Zero WGSL, Zero Shader Cross-Compilers):** All engine-authored and game-authored compute, mesh, ray-query, graphics, upscaling (`TaauRcas`), and declarative `RenderEffect` shaders live in modular `rust-gpu` crates (`crates/engine/shaders/core_shader_common` shared `#![no_std]` library + 4 stage-grouped crates: `core_shader_geometry`, `core_shader_raytracing`, `core_shader_shading`, and compile-time-isolated `core_shader_mesh`, alongside external crates such as `crates/fx_fresnel_rim`) compiled with `spirv-builder 0.11.0` (`spirv-unknown-vulkan1.4`, `SpirvBuilder::multimodule(true)` with `env_shader_spv_path = false`, `spirv-opt` disabled in debug builds while keeping `spirv-val` enabled, and one unified `OUT_DIR` module manifest) and loaded directly via `vkCreateShaderModule`. Shaders standardize on the frozen `crates/shader_abi` Set 0 (persistent bindless textures + samplers + `FrameConstants`) + Set 1 (`pushDescriptor` bound storage buffers/images) + push-constant pool discriminators/element offsets (no shader-side `PhysicalStorageBuffer` pointers, keeping host-side BDA strictly for Vulkan AS builds). All runtime and `crates/asset_pipeline` crates use strictly pure-Rust dependencies (with `spirv-builder`'s transitive `spirv-tools-sys` as the sole shader-build exception).
3. **Scoped `unsafe` Isolation & Real-HW Vulkan 1.4 Validation:** Keep `unsafe_code = "deny"` in root `Cargo.toml` across all public APIs, simulation, gameplay, `shader_abi`, `asset_pipeline`, and `fx_fresnel_rim`. Isolate `#[allow(unsafe_code)]` strictly inside two private audited boundaries with explicit `// SAFETY:` comments and mandatory `VK_LAYER_KHRONOS_validation` testing directly on real Vulkan 1.4 ray-tracing hardware:
   - `crates/engine/src/gpu/` (private Vulkan 1.4 `ash` + `gpu-allocator` backend), and
   - `crates/engine/src/assets/mmap_store.rs` (read-only immutable `mmap` slices).
4. **Zero-Loading-Screen Async Pop-In (Frame-Pacing First):** Never stall simulation or rendering on disk I/O, decompression, GPU upload, BLAS build/compaction, or physics splicing. Accept visible asynchronous pop-in over frame-rate stutter.
5. **Independent Per-Subsystem Residency Policies & Dynamic VRAM Clamping:** Physics, Geometry/LOD, Ray-Tracing BLAS, Actors/AI, and GPU-Feedback Mipmap Streaming each own independent spatial residency policies and scaling parameters (no coupled monolithic sector rings), with VRAM pools dynamically clamped via `VK_EXT_memory_budget` at startup (`<= 75%` of available `DEVICE_LOCAL` heap budget, reserving fixed targets/pools + `BLAS_POOL_BUDGET_MB` first, then splitting remaining headroom `25%` static geometry / `75%` texture streaming up to tier ceilings).
6. **Lightweight Streaming Pacing (No Runtime Millisecond Timers):** Use only a fixed-size Pass 1 staging ring (`STAGING_RING_MB`, optionally supplemented by Vulkan 1.4 `hostImageCopy` for small mip tails and UI RGBA8), runtime-preset per-frame static BLAS build count and triangle caps (`STATIC_BLAS_BUILDS_PER_FRAME`, `STATIC_BLAS_TRIS_PER_FRAME`), and `VK_EXT_memory_budget`-clamped VRAM budgets (`STATIC_GEOMETRY_ARENA_MB`, `BLAS_POOL_BUDGET_MB`, `TEXTURE_STREAM_BUDGET_MB`). Millisecond figures are design-time references and offline QA profiler targets, never runtime timers.
7. **Zero-Lag Pass 2a / Pass 2b / Pass 3 Ordering & 11-Pass Unified Viewmodel Pipeline:** Execute **Pass 2a (Compute Meshlet Skinning)** before **Pass 3 (In-Place Dynamic BLAS Refit, Async Static BLAS Compaction, and Active-Radius TLAS Rebuild)** and **Pass 4 (World Thin Prepass)** so rasterization, ray queries, and lighting read identical Frame N poses, while running **Pass 2b (Dynamic TOD Sky LUT / Amortized IBL Compute)** asynchronously ahead of **Pass 7 (Demodulated ReSTIR DI, Reflections, Radiance Cascades)** (overlappable with Pass 4/5 via whole-image QFOT) so Passes 7, 8, 9, and 10 read identical Frame N sky/IBL state. Partition first-person reverse-Z viewports strictly into `[0.0, 0.95]` (world across Pass 4/5, with world Hi-Z tests scaling `z_ndc` by `0.95`) and `[0.95, 1.0]` (viewmodel drawn at the end of Pass 5 after the finalized half-res world Hi-Z update and single-phase transparent cull, packing 1-bit `is_viewmodel` into `R8_UINT`, excluded from both Hi-Z and TLAS) so weapons receive full ReSTIR DI, reflections, and GI with zero wall clipping and zero Hi-Z contamination in an **11-pass** Render Graph.
8. **Zero Runtime PSO Stutter & Wave-Portable Subgroups:** Precompile all fixed bindless compute, mesh, and graphics pipelines (including registered `RenderEffect` pipelines) once at startup backed by `VkPipelineCache`. Write all subgroup compute shaders wave-size-agnostic (`#[spirv(subgroup_size)]`, 128-bit `SubgroupMask`) with an opt-in Wave32 pipeline hint (`subgroupSizeControl`, `requiredSubgroupSize = 32` when supported by the adapter).

## 2. Baseline Codebase Readiness Audit

Before Phase 0 expansion, the workspace (`ash 0.38`, `ash-window 0.13`, `gpu-allocator 0.28`, `spirv-builder 0.11.0`, `spirv-std 0.11.0`, `glam 0.34.1`, `rapier3d 0.36.1`, `winit 0.30.13`, Rust edition `2024`) has these completed foundations and remaining structural gaps:

### Ready Foundations
- **Private Vulkan 1.3 Baseline (`crates/engine/src/gpu/`):** `ash 0.38` + `ash-window 0.13` + `gpu-allocator 0.28` device/swapchain/dynamic-rendering/`synchronization2` renderer, `spirv-unknown-vulkan1.3` shader builds, `EngineError::Gpu` typed startup errors, declarative `RenderEffect` (`EffectShaderSpec`, zero `ash`/`unsafe` in `crates/fx_fresnel_rim`), private `UiRenderTarget::composite_rgba8`, and headless Vulkan 1.3 SPIR-V pipeline validation tests.
- **Simulation/Render Isolation (`crates/engine/src/runner.rs`, `snapshot.rs`):** `Renderer` is private and reads immutable double-buffered `RenderSnapshot<G>`. `RenderSchedule::Parallel` overlaps `Sim N+1` with `Render N`.
- **Shared ABI (`crates/shader_abi/src/lib.rs`):** `#![no_std]` crate with scalar-backed `#[repr(C)]` types (`Vec4f`, `Mat4f`) and optional `bytemuck` derives shared by `engine` and `core_shader`.
- **Contiguous Transform Storage (`crates/engine/src/physics.rs`):** `SoaStorage` maintains dense `positions`, `rotations`, and `bounds` arrays.
- **Decoupled UI (`crates/engine/src/ui.rs`):** `UiOverlay::render` runs after the 3D scene pass via `UiRenderTarget::composite_rgba8`.

### Structural Gaps Addressed by Phases 0 to 3
1. **Immediate-Mode Box Snapshot vs. Retained GPU Scene (`world.rs`, `gpu/scene_pipeline.rs`, `runner.rs`):** `collect_render_meshes` performs a hardcoded 200 m CPU octree query and clones box primitives every frame. Must transition to a retained GPU scene fed by a frame-index-fenced append-only monotonic delta queue (`delta.frame_index <= snapshot.frame_index`, accumulating mutations across `Sim` steps so `Parallel -> Sequential` overwrites and pre-`resumed` `GameApp::init` spawns never drop updates and `Sim N+1` never leaks into `Render N`) plus per-frame dynamic state (previous-frame transforms for motion vectors and `history_reset` invalidation flags).
2. **Missing Asset Registry & Upload Queue (`runner.rs`, `world.rs`):** `SimRunner::new` runs `GameApp::init` before `VulkanDevice` exists. Requires a device-independent opaque handle registry bridged to an async GPU upload queue.
3. **Strict Vulkan 1.4 Minimum Upgrade, Frame-Sync Migration & Render Graph (`gpu/device.rs`, `gpu/renderer.rs`, `gpu/scene_pipeline.rs`):** The completed baseline currently checks `API_VERSION_1_3` with `FRAMES_IN_FLIGHT = 2` and binary `vk::Fence`. Phase 0 upgrades startup to enforce **strict Vulkan 1.4 minimum** (`ApplicationInfo::api_version = 1.4.0`, `props.api_version >= 1.4.0`, rejecting any sub-1.4 or non-RT adapter), compiles engine and `fx_fresnel_rim` shaders to `spirv-unknown-vulkan1.4` (splitting `core_shader` into `core_shader_common` + 4 stage-grouped crates), enables exact Vulkan feature structs (Vulkan 1.0 `VkPhysicalDeviceFeatures`: `fragment_stores_and_atomics`, `shader_storage_image_extended_formats`, `shader_storage_image_write_without_format`, `shader_storage_image_read_without_format`, `shader_int16`, `depth_clamp`; `PhysicalDeviceVulkan11Features`: `storage_buffer16_bit_access`; `PhysicalDeviceVulkan12Features`: `timeline_semaphore`, `buffer_device_address`, `draw_indirect_count`, `scalar_block_layout`, `runtime_descriptor_array`, `descriptor_binding_partially_bound`, `descriptor_binding_sampled_image_update_after_bind`, `descriptor_binding_variable_descriptor_count`, `shader_sampled_image_array_non_uniform_indexing`; `PhysicalDeviceVulkan13Features`: `dynamic_rendering`, `synchronization2`, `subgroup_size_control`, `compute_full_subgroups`; `PhysicalDeviceRayQueryFeaturesKHR`; `PhysicalDeviceAccelerationStructureFeaturesKHR`; optional `PhysicalDeviceMeshShaderFeaturesEXT` / `PhysicalDeviceHostImageCopyFeaturesEXT`; plus `VkPhysicalDeviceSubgroupProperties` and `requiredSubgroupSizeStages` verification) and enables only the device extensions actually consumed (`VK_KHR_push_descriptor`, `VK_KHR_ray_query`, `VK_KHR_acceleration_structure`, `VK_KHR_deferred_host_operations`, `VK_EXT_memory_budget`, `VK_KHR_swapchain`, optional `VK_EXT_mesh_shader` and `VK_EXT_host_image_copy`), migrates `VulkanRenderer` to triple-buffered dynamic pools + timeline-semaphore submit-serial reclamation (`completed_timeline_value >= freed_at_submit_serial`), adds optional DMA transfer/async compute queues with hybrid cross-queue sync (`CONCURRENT` buffers, `EXCLUSIVE` + whole-image QFOT for images), `VkPipelineCache`, private transient alias `vk::DeviceMemory` heaps, resize/style-switch/device-lost lifecycle handling, and the internal Render Graph barrier tracker.
4. **Missing Rendering Domain Primitives (`physics.rs`, `snapshot.rs`, `save.rs`, `world.rs`, `effect.rs`):** Needs stable persistent `AssetId` and `EffectKey` (`&'static str`) keys vs. ephemeral runtime handles (`MeshHandle`, `MaterialHandle`, `TextureHandle`, `SkeletonHandle`, `FontHandle`, `EffectId`), dynamic lights (`LightId` handle table / commands), highlight categories, cutout flags, dual `CameraMode` (First-Person + viewmodel vs. Isometric + cutout target), `VisualStyle`, `UpscalerBackend`, 3D MSDF signs, and `AssetId` + `EffectKey` + animation-state `ActorCheckpoint` schemas.
5. **GPU-Driven Multi-Stage `RenderEffect` Evolution (`effect.rs`, `crates/shader_abi`, `crates/fx_fresnel_rim`):** `RenderEffect` is already declarative (`EffectShaderSpec`), currently wired to CPU box vertex ranges, ephemeral `EffectId(u32)` checkpoints, and legacy Set 0/Set 1 constants. Phase 0/3 adds stable `EffectKey` (`&'static str`), migrates `crates/shader_abi` to the frozen Set 0 (bindless + samplers + `FrameConstants`) / Set 1 (`pushDescriptor` per-stage transient bindings) / Push-Constant ABI, and evolves `EffectShaderSpec` to typed Pass-8 fragment-only hooks (overlay vs. opaque replacement reusing engine `#[spirv(invariant)]` prepass front-ends), Pass-10 transparent hooks (with optional custom vertex/mesh entry points), and Pass-11 screen-space post hooks backed by per-`EffectId` indirect/mesh queues emitted by Pass 4/5 and GPU instance `EffectAttachment` parameters.
6. **Full-World `Octree::rebuild` (`physics.rs`):** Rebuilds the entire octree on every spawn, despawn, or `SetPosition`. Must separate versioned pre-baked static sector colliders from Rapier's incremental dynamic broadphase.
7. **Large-World Precision (`physics.rs`, `snapshot.rs`, `world.rs`, `save.rs`):** `rapier3d` and `glam::Vec3` use `f32`. Seamless large worlds require canonical `DVec3` across `ActorSpawnDesc`, `PhysicsCommand`, `WorldReadView`, `SpatialQuery`, `Aabb3`, `RaycastHit`, `CameraSnapshot`, `GizmoBox`, and `ActorCheckpoint`, with active-origin rebasing for `rapier3d` and camera-relative `f32` rebasing in Pass 1.

## 4. Phased Implementation Plan

### Phase 0: Vulkan 1.4 Capabilities, `rust-gpu` Multi-Module Spike, Render Graph Barriers, Timeline Sync, GPU Arenas & `shader_abi`
- **Spec Sections:** 1, 7, 8, 18.
- **Dependencies:** None (builds directly on the completed `ash` + `gpu-allocator` baseline).
- **Deliverables:**
  1. **Modular `rust-gpu 0.11.0` Vulkan 1.4 Capability Spike & Existing Test Migration (`crates/engine/build.rs`, `crates/engine/shaders/`, `crates/fx_fresnel_rim/build.rs`, `gpu/scene_pipeline.rs`, `gpu/ui_pipeline.rs`):**
     - Split `core_shader` into `core_shader_common` + 4 stage-grouped crates (`core_shader_geometry`, `core_shader_raytracing`, `core_shader_shading`, `core_shader_mesh`) and migrate `crates/engine/build.rs` and `crates/fx_fresnel_rim/build.rs` to `spirv-unknown-vulkan1.4`. Configure `SpirvBuilder::multimodule(true)` with `env_shader_spv_path = false` (disabling `spirv-opt` in debug builds while keeping `spirv-val` enabled; enabling `spirv-opt` in release), writing one unified `OUT_DIR` manifest so `OpCapability MeshShadingEXT` stays compile-time isolated in `core_shader_mesh` and single-pass incremental builds take `2-6 s`.
     - Update `scene_pipeline.rs`, `ui_pipeline.rs`, and the two existing Vulkan 1.3 tests (`crates/engine/src/lib.rs` `core_shader_compiles_on_vulkan_1_3` and `crates/fx_fresnel_rim/src/lib.rs` `fresnel_rim_shader_emits_valid_spirv_and_compiles_on_vulkan`) from `CORE_SHADER_SPV` single-module env usage to the `OUT_DIR` manifest, splitting CPU SPIR-V magic/alignment checks from `#[ignore]` hardware Vulkan 1.4 pipeline tests.
     - Verify pure `rust-gpu` compilation and direct `vkCreateShaderModule` / pipeline creation on real Vulkan 1.4 RT hardware with `VK_LAYER_KHRONOS_validation` for: wave-size-agnostic subgroups (`#[spirv(subgroup_size)]`, 128-bit `SubgroupMask`, ballot/shuffle/scan) + `#[spirv(workgroup)]` shared memory & subgroup barriers + opt-in Wave32 `subgroupSizeControl` hint, unsized `spirv_std::RuntimeArray<Image!(...)>` `NonUniform` bindless sampling (`UPDATE_AFTER_BIND` + `VARIABLE_DESCRIPTOR_COUNT`, in both fragment and compute stages), Set-1 `pushDescriptor` storage buffers + 128 B push constants (`#[spirv(push_constant)]`), `&[u16]` 16-bit storage buffer access (`storage_buffer16_bit_access`, with `u32`-packed bit-shift fallback if `rustc_codegen_spirv 0.11.0` trips), `format = unknown` storage image writes (`shaderStorageImageWriteWithoutFormat` targeting `B10G11R11_UFLOAT_PACK32` and `R16G16B16A16_SFLOAT`), `RayQuery` (including non-opaque candidate-intersection alpha-test traversal), `#[spirv(early_fragment_tests)]` + fragment storage buffer writes (`fragmentStoresAndAtomics`), `#[spirv(invariant)]`, and isolated `core_shader_mesh` `TaskEXT`/`MeshEXT` mesh shaders.
  2. **Strict Vulkan 1.4 Device Enablement, `VK_EXT_memory_budget` Clamping, Format Probing & Dynamic Presets (`crates/engine/src/gpu/device.rs`, `config.rs`):**
     - Set `ApplicationInfo::api_version = vk::make_api_version(0, 1, 4, 0)` and enforce **strict Vulkan 1.4 RT minimum** (`props.api_version >= vk::make_api_version(0, 1, 4, 0)`, rejecting any adapter below Vulkan 1.4 or missing RT with `EngineError::Gpu(GpuError::UnsupportedAdapter)`) in both `new_windowed()` and single mandatory-RT `new_headless()` (zero sub-1.4 or software-rasterizer fallback). Enable exact Vulkan feature structs: Vulkan 1.0 `VkPhysicalDeviceFeatures` (`fragment_stores_and_atomics`, `shader_storage_image_extended_formats`, `shader_storage_image_write_without_format`, `shader_storage_image_read_without_format`, `shader_int16`, `depth_clamp`), `PhysicalDeviceVulkan11Features` (`storage_buffer16_bit_access`), `PhysicalDeviceVulkan12Features` (`timeline_semaphore`, `buffer_device_address` for host-side AS builds, `draw_indirect_count`, `scalar_block_layout`, `runtime_descriptor_array`, `descriptor_binding_partially_bound`, `descriptor_binding_sampled_image_update_after_bind`, `descriptor_binding_variable_descriptor_count`, `shader_sampled_image_array_non_uniform_indexing`), `PhysicalDeviceVulkan13Features` (`dynamic_rendering`, `synchronization2`, `subgroup_size_control`, `compute_full_subgroups`), `PhysicalDeviceRayQueryFeaturesKHR` (`ray_query`), `PhysicalDeviceAccelerationStructureFeaturesKHR` (`acceleration_structure`), optional `PhysicalDeviceMeshShaderFeaturesEXT` (`task_shader`, `mesh_shader`), optional `PhysicalDeviceHostImageCopyFeaturesEXT` (`host_image_copy`), and verify `VkPhysicalDeviceSubgroupProperties` (`BASIC | BALLOT | ARITHMETIC | SHUFFLE`), `VkPhysicalDeviceVulkan13Properties` (`requiredSubgroupSizeStages` containing `COMPUTE_BIT` and `minSubgroupSize <= 32 <= maxSubgroupSize`), and `maxPushConstantsSize >= 128 B`. Explicitly enable required device extensions in `vkCreateDevice::ppEnabledExtensionNames` (`VK_KHR_push_descriptor`, `VK_KHR_ray_query`, `VK_KHR_acceleration_structure`, `VK_KHR_deferred_host_operations`, `VK_EXT_memory_budget`, plus `VK_KHR_swapchain` when windowed, and optional `VK_EXT_mesh_shader` and `VK_EXT_host_image_copy` when supported; omit unused `maintenance5`/`maintenance6`/`dynamic_rendering_local_read`), plus optional dedicated DMA transfer + async compute queue families.
     - Probe `vkGetPhysicalDeviceFormatProperties` at startup for `VK_FORMAT_R16G16_SNORM` (`COLOR_ATTACHMENT_BIT`, falling back to `R16G16_SFLOAT`) and `VK_FORMAT_B10G11R11_UFLOAT_PACK32` (`STORAGE_IMAGE_BIT` + `COLOR_ATTACHMENT_BIT`, falling back transparently via `shaderStorageImageWriteWithoutFormat` to `R16G16B16A16_SFLOAT` across both Pass 7 radiance targets and Linear HDR Scene Color). Return typed `EngineError::Gpu(GpuError::UnsupportedAdapter)` when Vulkan 1.4 or required features are missing, and surface `VK_ERROR_DEVICE_LOST` as `EngineError::Gpu(GpuError::DeviceLost)`.
     - Auto-select runtime preset (`Radeon780M` at 30 FPS floor with off-screen world light grid off, `Radeon890M` at 60 FPS Performance `720p` internal / `0.5x` ReSTIR / `0.25x` GI / `<0.35` reflections + 40-50 FPS Quality toggle, `DiscreteDesktop` at 60+ FPS native with `0.75x` ReSTIR/GI and `0.5x` Reflections defaults + `1.0x` Quality toggle, `HighEnd4K` at 90+ FPS) applying deterministic `VK_EXT_memory_budget` clamping (`<= 75%` of available `DEVICE_LOCAL` heap budget: reserve fixed targets/pools + partitioned `BLAS_POOL_BUDGET_MB` first, then split remaining headroom `25%` `STATIC_GEOMETRY_ARENA_MB` / `75%` `TEXTURE_STREAM_BUDGET_MB` capped at tier ceilings); expose `VisualStyle` (`Realistic` | `Comic`) and `UpscalerBackend` (`TaauRcas`).
  3. **Frame-Sync Migration, Render Graph Barriers & QFOT, Transient Alias Heaps, `VkPipelineCache`, Memory Pools, Static Geometry Arena, Partitioned `BlasPool` & Synthetic Meshlet Fixture (`crates/engine/src/gpu/`, `assets/`):**
     - Migrate `VulkanRenderer` (`gpu/renderer.rs`, `gpu/scene_pipeline.rs`) from `FRAMES_IN_FLIGHT = 2` + binary `vk::Fence` to triple-buffered dynamic pools + timeline-semaphore submit serials, driving deferred arena/BLAS/texture reclamation and safe resize / `INTERNAL_RENDER_SCALE` / `Realistic <-> Comic` history-target teardown strictly from `completed_timeline_value >= freed_at_submit_serial` (skipping draw cleanly on `0x0` minimized windows).
     - Implement lightweight internal Render Graph state tracker emitting minimal `vkCmdPipelineBarrier2` layout/access transitions and whole-image Queue Family Ownership Transfers (QFOT release -> timeline semaphore -> acquire) for `EXCLUSIVE` cross-queue images (Pass 1 DMA textures, Pass 2b Sky/IBL) while creating shared sub-allocated geometry/AS/skinned buffers as `VK_SHARING_MODE_CONCURRENT` (collapsing to single-queue barriers on unified iGPUs / single-family adapters), binding per-pass transient resources via Set-1 `pushDescriptor`, and implementing two private raw `vk::DeviceMemory` transient alias heaps (one optimal-image heap with `VK_IMAGE_CREATE_ALIAS_BIT` and `UNDEFINED` layout barriers, one linear-buffer heap honoring `bufferImageGranularity` and `memoryTypeBits`, since `gpu-allocator 0.28` does not expose aliasing).
     - Implement on-disk `VkPipelineCache` load/save, triple-buffered dynamic pools (`SKINNED_VERTEX_POOL_MB`, `BONE_BUFFER_MB`, transient vertices), TLSF/free-list sub-allocated static geometry arena (retaining flat BLAS triangle-index slices + vertex tangent frames alongside meshlet buffers), partitioned exact-budget `BlasPool` (reserved Dynamic BLAS + TLAS + scratch slice separate from dedicated Static BLAS free-list slice using `vkGetAccelerationStructureBuildSizesKHR` + `VK_QUERY_TYPE_ACCELERATION_STRUCTURE_COMPACTED_SIZE_KHR`), fixed Pass 1 upload staging ring (`STAGING_RING_MB`, DMA transfer queue capable + optional `hostImageCopy` fast path for small mip tails / UI RGBA8), and triple-buffered host-mapped mipmap-feedback readback ring.
     - Define device-independent opaque handle types (`MeshHandle`, `MaterialHandle`, `TextureHandle`, `SkeletonHandle`, `FontHandle`) and a `~150 LOC` procedural synthetic meshlet fixture generator (64-vert / 124-tri boxes, spheres, and walls) so Phase 2 starts in parallel with Phase 1 immediately after Phase 0.
  4. **Shared ABI & Descriptor Set Layout Freeze (`crates/shader_abi/src/lib.rs`), Phase 1 Crate Smoke Check & Docs Sync:**
