# Implementation Plan: Dual-Camera 3D RPG Graphics & Streaming Architecture

This document defines the phased implementation plan for realizing [Architectural Design Specifications for a Dual-Camera 3D RPG Graphics Engine](graphics-architecture.md) inside Dragon Engine while preserving all runtime invariants in [Engine Architecture Principles](engine-architecture.md).

---

## 1. Locked Architectural Decisions

These decisions are final and must not be reopened during implementation without an explicit Blueprint review:

1. **Strict Vulkan 1.4 Minimum Hardware via Private `ash 0.38` + `gpu-allocator 0.28` (Upgrade to `ash 0.39` on Release):** Target native **Vulkan 1.4** ray-tracing hardware exclusively (Linux including Steam Deck, and Windows) through private `ash 0.38`, `ash-window 0.13`, and pure-Rust `gpu-allocator 0.28` inside `crates/engine/src/gpu/`. Startup sets `ApplicationInfo::api_version = vk::make_api_version(0, 1, 4, 0)`, strictly requires a conformant Vulkan 1.4 ray-tracing adapter (`props.api_version >= vk::make_api_version(0, 1, 4, 0)`; zero sub-1.4 or software-rasterizer fallback), checks `vkEnumerateDeviceExtensionProperties` before enabling suffixed `ash 0.38` KHR/EXT extension loaders actually consumed (`VK_KHR_push_descriptor`, mandatory Vulkan 1.4 `VK_KHR_index_type_uint8`, optional `VK_EXT_host_image_copy`) in `vkCreateDevice::ppEnabledExtensionNames` until `ash 0.39` + matching `gpu-allocator` release on crates.io. Native macOS, DX12, Metal, WebAssembly, and `wgpu` are out of scope. Zero raw Vulkan handles are exposed outside `crates/engine`.
2. **Strict 100% `rust-gpu` Vulkan 1.4 SPIR-V with Modular Stage-Grouped Crates (Zero WGSL, Zero Shader Cross-Compilers):** All engine-authored and game-authored compute, mesh, ray-query, graphics, upscaling (`TaauRcas`), and declarative `RenderEffect` shaders live in modular `rust-gpu` crates (top-level `crates/shader_common` shared `#![no_std]` library with `crate-type = ["rlib"]`, never `dylib`, alongside `crates/shader_abi` so both engine shader crates and external `RenderEffect` workspaces share helpers cleanly + 4 stage-grouped `dylib` crates under `crates/engine/shaders/`: `core_shader_geometry`, `core_shader_raytracing`, `core_shader_shading`, and compile-time-isolated `core_shader_mesh`, alongside external crates such as `crates/fx_fresnel_rim`) compiled with `spirv-builder 0.11.0` (`spirv-unknown-vulkan1.4`, one shared `target_dir_path` using a 2-tuple capability split so `core_shader_geometry`, `core_shader_shading`, and `core_shader_raytracing` share one base RT capability/extension set while only `core_shader_mesh` adds `MeshShadingEXT`, compiling `-Zbuild-std=core` twice on clean builds rather than 4 times, `SpirvBuilder::multimodule(true)` with `env_shader_spv_path = Some(false)`, `.scalar_block_layout(true)`, `.release(false)` + `SpirvMetadata::NameVariables` in debug builds to skip `spirv-opt` cleanly without warnings while keeping `spirv-val` enabled, plus an optional per-crate release/opt toggle for `core_shader_raytracing` if unoptimized debug ray-query frame times become impractical, and one unified `OUT_DIR` module manifest) and loaded directly via `vkCreateShaderModule`. Shaders standardize on the frozen `crates/shader_abi` 2-set + inter-stage ABI: **Set 0** (`SET_BINDLESS_GLOBAL = 0`, triple-buffered `[vk::DescriptorSet; 3]` across 3 frames in flight so per-frame UBO/instance/light/material updates never violate `VUID-vkUpdateDescriptorSets-None-03047`, ordered so the variable-count bindless array is the highest binding per `VUID-VkDescriptorSetLayoutBindingFlagsCreateInfo-pBindingFlags-03004`: `b0` per-frame `FrameConstants` UBO, `b1` frozen `SAMPLER_COUNT = 5` immutable samplers, `b2..b13` persistent and per-frame-slot scene SSBOs including `GpuMaterial`, `GpuSubmeshDesc`, static geometry/meshlet arenas, rotating 3-slice skinned vertex ring `b8`, per-frame `GpuInstance` `b9`, per-frame `GpuLight` `b10`, clusters, and world light grid, `b14` unsized `RuntimeArray` sampled images using fresh-slot `S_new` swap across all 3 Set 0 instances so in-flight frames never read an overwritten slot; `UiPipeline` keeps its own private descriptor layout) + **Set 1** (`SET_PASS_TRANSIENT = 1`, `pushDescriptor` for per-pass transients, frozen Pass-8/10/11 `RenderEffect` inputs, and Pass 7 TLAS, verified `maxPushDescriptors >= 32`) + push-constant pool discriminators/element offsets (no shader-side `PhysicalStorageBuffer` pointers, keeping host-side BDA strictly for Vulkan AS builds) + frozen Pass-8 fragment-only inter-stage locations (`location 0..4`: `world_pos`, `world_normal`, `world_tangent`, `uv`, `flat instance_index`). All runtime crates (`engine` runtime, `shader_abi`, `fx_fresnel_rim`, `game`) compile strictly with pure-Rust dependencies; offline build tooling (`spirv-builder`'s `spirv-tools-sys`, plus an optional offline-only carve-out in `crates/asset_pipeline` if Phase 0's crate smoke check identifies missing skinned simplification or prohibitive CPU BC7 release bake times) stays isolated from runtime crates.
3. **Scoped `unsafe` Isolation & Real-HW Vulkan 1.4 Validation:** Keep `unsafe_code = "deny"` in root `Cargo.toml` across all public APIs, simulation, gameplay, `shader_abi`, `asset_pipeline`, and host `fx_fresnel_rim`. Isolate host `#[allow(unsafe_code)]` strictly inside two private audited boundaries with explicit `// SAFETY:` comments and mandatory `VK_LAYER_KHRONOS_validation` testing directly on real Vulkan 1.4 ray-tracing hardware:
   - `crates/engine/src/gpu/` (private Vulkan 1.4 `ash` + `gpu-allocator` backend), and
   - `crates/engine/src/assets/mmap_store.rs` (read-only immutable `mmap` slices via `memmap2` with an explicit immutable-archive safety contract).
   Isolated `#![no_std]` shader crates (`crates/shader_common` and `crates/engine/shaders/core_shader_*`, excluded from the root workspace) invoke `unsafe` `spirv-std 0.11.0` hardware intrinsics (`RuntimeArray::index`, `RayQuery::*`, `Image::write`, `set_mesh_outputs_ext`, `emit_mesh_tasks_ext`), wrapped via `crates/shader_common` helpers where appropriate.
4. **Zero-Loading-Screen Async Pop-In (Frame-Pacing First):** Never stall simulation or rendering on disk I/O, decompression, GPU upload, BLAS build/compaction, or physics splicing. Accept visible asynchronous pop-in over frame-rate stutter.
5. **Independent Per-Subsystem Residency Policies, User-Driven `GraphicsSettings` & Hard Physical Safety Clamping:** Physics, Geometry/LOD, Ray-Tracing BLAS, Actors/AI, and GPU-Feedback Mipmap Streaming each own independent spatial residency policies and scaling parameters (no coupled monolithic sector rings). All quality/scaling parameters live in explicit game/user-configurable `GraphicsSettings` (with generic `Low` / `Medium` / `High` / `Ultra` presets and per-feature knobs; the Runtime Hardware Scaling Matrix in `docs/graphics-architecture.md` is purely informative and the engine never blindly detects GPU model names to override settings). At startup, the engine applies only hard physical safety clamping against Vulkan device limits and `VK_EXT_memory_budget` (`<= 75%` of available `DEVICE_LOCAL` heap budget, reserving fixed targets/pools + `BLAS_POOL_BUDGET_MB` first, then splitting remaining headroom `25%` static geometry / `75%` texture streaming up to configured ceilings).
6. **Lightweight Streaming Pacing (No Runtime Millisecond Timers):** Use only a fixed-size Pass 1 staging ring (`STAGING_RING_MB` per-frame slice, `3 * STAGING_RING_MB` total host-visible ring, optionally supplemented by Vulkan 1.4 `hostImageCopy` for small mip tails and UI RGBA8), `GraphicsSettings`-configured per-frame static BLAS build count and triangle caps (`STATIC_BLAS_BUILDS_PER_FRAME`, `STATIC_BLAS_TRIS_PER_FRAME`), and `VK_EXT_memory_budget`-clamped VRAM budgets (`STATIC_GEOMETRY_ARENA_MB`, `BLAS_POOL_BUDGET_MB`, `TEXTURE_STREAM_BUDGET_MB`). Millisecond figures are design-time references and offline QA profiler targets, never runtime timers.
7. **Zero-Lag Pass 2a / Pass 2b / Pass 3 Ordering, Dual-Style Direct Lighting & 11-Pass Unified Viewmodel Pipeline:** Execute **Pass 2a (Compute Meshlet Skinning)** before **Pass 3 (In-Place Dynamic BLAS Refit, Async Static BLAS Compaction, and Active-Radius TLAS Rebuild)** and **Pass 4 (World Thin Prepass)** so rasterization, ray queries, and lighting read identical Frame N poses, while running **Pass 2b (Dynamic TOD Sky LUT / Amortized IBL Compute)** asynchronously ahead of **Pass 7 (Realistic Demodulated ReSTIR DI with NRD-style `EnvBRDF` remodulation / Comic Deterministic Sun + Top-3 Priority-Sorted Cluster-Light `R8G8B8A8_UNORM` Visibility Mask, Reflections, Radiance Cascades)** (overlappable with Pass 4/5 via whole-image QFOT) so Passes 7, 8, 9, and 10 read identical Frame N sky/IBL state. Partition first-person reverse-Z viewports strictly into `[0.0, 0.95]` (world across Pass 4/5 and Pass 11 highlights, with world Hi-Z tests scaling `z_ndc` by `0.95`) and `[0.95, 1.0]` (capsule-scaled `0.15x-0.20x` viewmodel around the camera eye with matching near/far planes drawn at the end of Pass 5 after the finalized half-res world Hi-Z update and single-phase transparent cull, packing 1-bit `is_viewmodel` into `R8_UINT`, excluded from both Hi-Z and TLAS) so weapons receive full ReSTIR DI, reflections, and GI with zero wall clipping, zero wall-penetration lighting inversion in Pass 7 TLAS ray queries, and zero Hi-Z contamination in an **11-pass** Render Graph.
8. **Zero Runtime PSO Stutter & Wave-Portable Subgroups:** Precompile all fixed bindless compute, mesh, and graphics pipelines (including registered `RenderEffect` pipelines) once at startup backed by `VkPipelineCache`. Write all subgroup compute shaders wave-size-agnostic (`#[spirv(subgroup_size)]`, 128-bit `SubgroupMask`) with an opt-in Wave32 pipeline hint (`subgroupSizeControl`, `requiredSubgroupSize = 32` when supported by the adapter).

## 2. Baseline Codebase Readiness Audit

Before Phase 0 expansion, the workspace (`ash 0.38`, `ash-window 0.13`, `gpu-allocator 0.28`, `spirv-builder 0.11.0`, `spirv-std 0.11.0`, `glam 0.34.1`, `rapier3d 0.36.1`, `winit 0.30.13`, Rust edition `2024`) has these completed foundations and remaining structural gaps:

### Ready Foundations
- **Private Vulkan 1.3 Baseline (`crates/engine/src/gpu/`):** `ash 0.38` + `ash-window 0.13` + `gpu-allocator 0.28` device/swapchain/dynamic-rendering/`synchronization2` renderer, `spirv-unknown-vulkan1.3` shader builds, `EngineError::Gpu` typed startup errors, declarative `RenderEffect` (`EffectShaderSpec`, zero `ash`/`unsafe` in `crates/fx_fresnel_rim`), private `UiRenderTarget::composite_rgba8`, and headless Vulkan 1.3 SPIR-V pipeline validation tests.
- **Simulation/Render Isolation (`crates/engine/src/runner.rs`, `snapshot.rs`):** `Renderer` is private and reads immutable double-buffered `RenderSnapshot<G>`. `RenderSchedule::Parallel` overlaps `Sim N+1` with `Render N`.
- **Shared ABI (`crates/shader_abi/src/lib.rs`):** `#![no_std]` crate with scalar-backed `#[repr(C)]` types (`Vec4f`, `Mat4f`) and optional `bytemuck` derives shared by `engine` and `core_shader`.
- **Contiguous Transform Storage (`crates/engine/src/physics.rs`):** `SoaStorage` maintains dense `positions`, `rotations`, and `bounds` arrays.
- **Decoupled UI (`crates/engine/src/ui.rs`):** `UiOverlay::render` runs after the 3D scene pass via `UiRenderTarget::composite_rgba8`.

### Structural Gaps Addressed by Phases 0 to 3
1. **Immediate-Mode Box Snapshot vs. Retained GPU Scene (`world.rs`, `gpu/scene_pipeline.rs`, `runner.rs`):** `collect_render_meshes` performs a hardcoded 200 m CPU octree query and clones box primitives every frame. Must transition to a retained GPU scene fed by a frame-index-fenced append-only monotonic delta queue (`delta.frame_index <= snapshot.frame_index`, accumulating mutations across `Sim` steps so `Parallel -> Sequential` overwrites and pre-`resumed` `GameApp::init` spawns never drop updates and `Sim N+1` never leaks into `Render N`) plus per-frame dynamic state (previous-frame transforms for motion vectors and `history_reset` invalidation flags).
2. **Missing Asset Registry & Upload Queue (`runner.rs`, `world.rs`):** `SimRunner::new` runs `GameApp::init` before `VulkanDevice` exists. Requires a device-independent opaque handle registry bridged to an async GPU upload queue.
3. **Strict Vulkan 1.4 Minimum Upgrade, Frame-Sync Migration & Render Graph (`gpu/device.rs`, `gpu/renderer.rs`, `gpu/scene_pipeline.rs`, `gpu/ui_pipeline.rs`):** The completed baseline currently checks `API_VERSION_1_3` with `FRAMES_IN_FLIGHT = 2` (shared across `renderer.rs`, `scene_pipeline.rs`, and `ui_pipeline.rs`) and binary `vk::Fence`. Phase 0 upgrades startup to enforce **strict Vulkan 1.4 minimum** (`ApplicationInfo::api_version = 1.4.0`, `props.api_version >= 1.4.0`, rejecting any sub-1.4 or non-RT adapter), compiles engine and `fx_fresnel_rim` shaders to `spirv-unknown-vulkan1.4` (splitting `core_shader` into top-level `crates/shader_common` + 4 stage-grouped crates), enables exact Vulkan feature structs (Vulkan 1.0 `VkPhysicalDeviceFeatures`: `multi_draw_indirect`, `draw_indirect_first_instance`, `sampler_anisotropy`, `fragment_stores_and_atomics`, `shader_storage_image_extended_formats`, `shader_storage_image_write_without_format`, `shader_int16`, `depth_clamp`; read-only compute inputs use `SAMPLED_IMAGE` fetch so `shader_storage_image_read_without_format` is not required; `PhysicalDeviceVulkan11Features`: `storage_buffer16_bit_access`; `PhysicalDeviceVulkan12Features`: `timeline_semaphore`, `buffer_device_address`, `draw_indirect_count`, `scalar_block_layout`, `runtime_descriptor_array`, `descriptor_binding_partially_bound`, `descriptor_binding_sampled_image_update_after_bind`, `descriptor_binding_variable_descriptor_count`, `shader_sampled_image_array_non_uniform_indexing`; `PhysicalDeviceVulkan13Features`: `dynamic_rendering`, `synchronization2`, `subgroup_size_control`, `compute_full_subgroups`; `PhysicalDeviceRayQueryFeaturesKHR`; `PhysicalDeviceAccelerationStructureFeaturesKHR`; mandatory Vulkan 1.4 `PhysicalDeviceIndexTypeUint8FeaturesKHR`; optional `PhysicalDeviceMeshShaderFeaturesEXT` (gated on `maxMeshOutputVertices >= 64 && maxMeshOutputPrimitives >= 124`) / `PhysicalDeviceHostImageCopyFeaturesEXT`; plus `VkPhysicalDeviceSubgroupProperties`, `requiredSubgroupSizeStages`, and `PhysicalDevicePushDescriptorPropertiesKHR::max_push_descriptors >= 32` verification) and enables only the advertised device extensions actually consumed (`VK_KHR_push_descriptor`, `VK_KHR_index_type_uint8`, `VK_KHR_ray_query`, `VK_KHR_acceleration_structure`, `VK_KHR_deferred_host_operations`, `VK_EXT_memory_budget`, `VK_KHR_swapchain`, optional `VK_EXT_mesh_shader`, and optional `VK_EXT_host_image_copy`), migrates `VulkanRenderer` and `UiPipeline` to triple-buffered dynamic pools + timeline-semaphore submit-serial reclamation (`completed_timeline_value >= freed_at_submit_serial`) + cross-frame GPU-to-GPU timeline dependencies for single-buffered async-queue resources, adds optional DMA transfer/async compute queues with hybrid cross-queue sync (`CONCURRENT` buffers, `EXCLUSIVE` + whole-image QFOT for images), `VkPipelineCache`, private transient alias `vk::DeviceMemory` heaps, resize/style-switch/device-lost lifecycle handling, and the internal Render Graph barrier tracker.
4. **Missing Rendering Domain Primitives (`physics.rs`, `snapshot.rs`, `save.rs`, `world.rs`, `effect.rs`):** Needs stable persistent `AssetId` and `EffectKey` (`&'static str`) keys vs. ephemeral runtime handles (`MeshHandle`, `MaterialHandle`, `TextureHandle`, `SkeletonHandle`, `FontHandle`, `EffectId`), dynamic lights (`LightId` handle table / commands), highlight categories, cutout flags, dual `CameraMode` (First-Person + viewmodel vs. Isometric + cutout target), `VisualStyle`, `UpscalerBackend`, 3D MSDF signs, and `AssetId` + `EffectKey` + animation-state `ActorCheckpoint` schemas.
5. **GPU-Driven Multi-Stage `RenderEffect` Evolution (`effect.rs`, `crates/shader_abi`, `crates/fx_fresnel_rim`):** `RenderEffect` is already declarative (`EffectShaderSpec`), currently wired to CPU box vertex ranges, ephemeral `EffectId(u32)` checkpoints, and legacy Set 0/Set 1 constants. Phase 0/3 adds stable `EffectKey` (`&'static str`), migrates `crates/shader_abi` to the frozen Set 0 (triple-buffered `[vk::DescriptorSet; 3]`, per-frame `FrameConstants`, 5 immutable samplers, fixed-handle scene SSBOs, highest-binding bindless `RuntimeArray`) / Set 1 (`pushDescriptor` per-stage transient bindings) / Push-Constant / Pass-8 inter-stage `location 0..4` ABI, and evolves `EffectShaderSpec` to typed Pass-8 fragment-only hooks (overlay vs. opaque replacement reusing engine `#[spirv(invariant)]` prepass front-ends), Pass-10 transparent hooks (with optional custom vertex entry points and separately isolated `MeshEXT` fallback pairs for non-mesh GPUs), and Pass-11 screen-space post hooks backed by per-`EffectId` indirect/mesh queues emitted by Pass 4/5 and GPU instance `EffectAttachment` parameters.
6. **Full-World `Octree::rebuild` (`physics.rs`):** Rebuilds the entire octree on every spawn, despawn, or `SetPosition`. Must separate versioned pre-baked static sector colliders from Rapier's incremental dynamic broadphase.
7. **Large-World Precision (`physics.rs`, `snapshot.rs`, `world.rs`, `save.rs`):** `rapier3d` and `glam::Vec3` use `f32`. Seamless large worlds require canonical `DVec3` across `ActorSpawnDesc`, `PhysicsCommand`, `WorldReadView`, `SpatialQuery`, `Aabb3`, `RaycastHit`, `CameraSnapshot`, `GizmoBox`, and `ActorCheckpoint`, with active-origin rebasing for `rapier3d` and camera-relative `f32` rebasing in Pass 1.

     - Verify pure `rust-gpu` compilation and direct `vkCreateShaderModule` / pipeline creation on real Vulkan 1.4 RT hardware with `VK_LAYER_KHRONOS_validation` for: wave-size-agnostic subgroups (`#[spirv(subgroup_size)]`, 128-bit `SubgroupMask`, ballot/shuffle/scan) + `#[spirv(workgroup)]` shared memory & subgroup barriers + opt-in Wave32 `subgroupSizeControl` hint, unsized `spirv_std::RuntimeArray<Image!(...)>` `NonUniform` bindless sampling at Set 0's highest binding (`UPDATE_AFTER_BIND` + `VARIABLE_DESCRIPTOR_COUNT`, in both fragment and compute stages), Set-1 `pushDescriptor` storage buffers/images + 128 B push constants (`#[spirv(push_constant)]`), `&[u16]` 16-bit storage buffer access (`storage_buffer16_bit_access`, with `u32`-packed bit-shift fallback if `rustc_codegen_spirv 0.11.0` trips), formatless storage image writes (`Image!(2D, type = f32, sampled = false)` emitting `ImageFormat::Unknown` under `shaderStorageImageWriteWithoutFormat`, targeting `B10G11R11_UFLOAT_PACK32` and `R16G16B16A16_SFLOAT`, with read-only compute inputs using `SAMPLED_IMAGE` fetch), `RayQuery` (including non-opaque candidate-intersection alpha-test traversal), `#[spirv(fragment(early_fragment_tests))]` + fragment storage buffer writes (`fragmentStoresAndAtomics`), `#[spirv(invariant)]`, and isolated `core_shader_mesh` `TaskEXT`/`MeshEXT` mesh shaders.
  2. **Strict Vulkan 1.4 Device Enablement, `VK_EXT_memory_budget` Clamping, Format Probing & `GraphicsSettings` (`crates/engine/src/gpu/device.rs`, `config.rs`):**

`PhysicalDeviceVulkan12Features` (`timeline_semaphore`, `buffer_device_address` for host-side AS builds, `draw_indirect_count`, `scalar_block_layout`, `runtime_descriptor_array`, `descriptor_binding_partially_bound`, `descriptor_binding_sampled_image_update_after_bind`, `descriptor_binding_variable_descriptor_count`, `shader_sampled_image_array_non_uniform_indexing`),
