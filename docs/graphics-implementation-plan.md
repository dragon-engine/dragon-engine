# Implementation Plan: Dual-Camera 3D RPG Graphics & Streaming Architecture

This document defines the phased implementation plan for realizing [Architectural Design Specifications for a Dual-Camera 3D RPG Graphics Engine](graphics-architecture.md) inside Dragon Engine while preserving all runtime invariants in [Engine Architecture Principles](engine-architecture.md).

---

## 1. Locked Architectural Decisions

These decisions are final and must not be reopened during implementation without an explicit Blueprint review:

1. **Strict Vulkan 1.4 Minimum Hardware via Private `ash 0.38` + `gpu-allocator 0.28` (Upgrade to `ash 0.39` on Release):** Target native **Vulkan 1.4** ray-tracing hardware exclusively (Linux including Steam Deck, and Windows) through private `ash 0.38`, `ash-window 0.13`, and pure-Rust `gpu-allocator 0.28` inside `crates/engine/src/gpu/`. Startup sets `ApplicationInfo::api_version = vk::make_api_version(0, 1, 4, 0)`, strictly requires a conformant Vulkan 1.4 ray-tracing adapter (`props.api_version >= vk::make_api_version(0, 1, 4, 0)`; zero sub-1.4 or software-rasterizer fallback), and explicitly enables only the `ash 0.38` KHR/EXT extension loaders actually consumed (`VK_KHR_push_descriptor`, optional `VK_EXT_host_image_copy`) in `vkCreateDevice::ppEnabledExtensionNames` until `ash 0.39` + matching `gpu-allocator` release on crates.io. Native macOS, DX12, Metal, WebAssembly, and `wgpu` are out of scope. Zero raw Vulkan handles are exposed outside `crates/engine`.
2. **Strict 100% `rust-gpu` Vulkan 1.4 SPIR-V with Multi-Module Isolation (Zero WGSL, Zero Shader Cross-Compilers):** All engine-authored and game-authored compute, mesh, ray-query, graphics, upscaling (`TaauRcas`), and declarative `RenderEffect` shaders live in `crates/engine/shaders/core_shader` and external `rust-gpu` crates (such as `crates/fx_fresnel_rim`) compiled with `spirv-builder 0.11.0` (`spirv-unknown-vulkan1.4`, `SpirvBuilder::multimodule(true)` with `env_shader_spv_path = false` and an `OUT_DIR` module manifest generated from `result.module.unwrap_multi()` so optional `TaskEXT`/`MeshEXT` modules stay isolated from non-mesh GPUs, with a separate `core_shader_mesh` crate as explicit Phase 0 fallback) into Cargo `OUT_DIR` and loaded directly via `vkCreateShaderModule`. Shaders standardize on the frozen `crates/shader_abi` Set 0 (persistent bindless textures + samplers + `FrameConstants`) + Set 1 (`pushDescriptor` bound storage buffers/images) + push-constant pool discriminators/element offsets (no shader-side `PhysicalStorageBuffer` pointers, keeping host-side BDA strictly for Vulkan AS builds). All runtime and `crates/asset_pipeline` crates use strictly pure-Rust dependencies (with `spirv-builder`'s transitive `spirv-tools-sys` as the sole shader-build exception).
3. **Scoped `unsafe` Isolation & Real-HW Vulkan 1.4 Validation:** Keep `unsafe_code = "deny"` in root `Cargo.toml` across all public APIs, simulation, gameplay, `shader_abi`, `asset_pipeline`, and `fx_fresnel_rim`. Isolate `#[allow(unsafe_code)]` strictly inside two private audited boundaries with explicit `// SAFETY:` comments and mandatory `VK_LAYER_KHRONOS_validation` testing directly on real Vulkan 1.4 ray-tracing hardware:
   - `crates/engine/src/gpu/` (private Vulkan 1.4 `ash` + `gpu-allocator` backend), and
   - `crates/engine/src/assets/mmap_store.rs` (read-only immutable `mmap` slices).
4. **Zero-Loading-Screen Async Pop-In (Frame-Pacing First):** Never stall simulation or rendering on disk I/O, decompression, GPU upload, BLAS build/compaction, or physics splicing. Accept visible asynchronous pop-in over frame-rate stutter.
5. **Independent Per-Subsystem Residency Policies & Dynamic VRAM Clamping:** Physics, Geometry/LOD, Ray-Tracing BLAS, Actors/AI, and GPU-Feedback Mipmap Streaming each own independent spatial residency policies and scaling parameters (no coupled monolithic sector rings), with VRAM pools dynamically clamped via `VK_EXT_memory_budget` at startup (`<= 75%` of available `DEVICE_LOCAL` heap budget, reserving fixed targets/pools + `BLAS_POOL_BUDGET_MB` first, then splitting remaining headroom `25%` static geometry / `75%` texture streaming up to tier ceilings).
6. **Lightweight Streaming Pacing (No Runtime Millisecond Timers):** Use only a fixed-size Pass 1 staging ring (`STAGING_RING_MB`, optionally supplemented by Vulkan 1.4 `hostImageCopy` for small mip tails and UI RGBA8), runtime-preset per-frame static BLAS build count and triangle caps (`STATIC_BLAS_BUILDS_PER_FRAME`, `STATIC_BLAS_TRIS_PER_FRAME`), and `VK_EXT_memory_budget`-clamped VRAM budgets (`STATIC_GEOMETRY_ARENA_MB`, `BLAS_POOL_BUDGET_MB`, `TEXTURE_STREAM_BUDGET_MB`). Millisecond figures are design-time references and offline QA profiler targets, never runtime timers.
7. **Zero-Lag Pass 2a / Pass 2b / Pass 3 Ordering & 11-Pass Unified Viewmodel Pipeline:** Execute **Pass 2a (Compute Meshlet Skinning)** before **Pass 3 (In-Place Dynamic BLAS Refit, Async Static BLAS Compaction, and Active-Radius TLAS Rebuild)** and **Pass 4 (Thin Prepass)** so rasterization, ray queries, and lighting read identical Frame N poses, while running **Pass 2b (Dynamic TOD Sky LUT / Amortized IBL Compute)** asynchronously ahead of **Pass 7 (Demodulated ReSTIR DI, Reflections, Radiance Cascades)** (overlappable with Pass 4/5) so Passes 7, 8, 9, and 10 read identical Frame N sky/IBL state. Partition first-person reverse-Z viewports strictly into `[0.0, 0.95]` (world) and `[0.95, 1.0]` (viewmodel, 1-bit `is_viewmodel` packed into `R8_UINT`, excluded from TLAS) directly inside Pass 4/5 Thin Prepass and Pass 8 Forward Shading so weapons receive full ReSTIR DI, reflections, and GI with zero wall clipping in an **11-pass** Render Graph.
8. **Zero Runtime PSO Stutter & Wave-Portable Subgroups:** Precompile all fixed bindless compute, mesh, and graphics pipelines (including registered `RenderEffect` pipelines) once at startup backed by `VkPipelineCache`. Write all subgroup compute shaders wave-size-agnostic (`#[spirv(subgroup_size)]`, 128-bit `SubgroupMask`) with an opt-in Wave32 pipeline hint (`subgroupSizeControl`, `requiredSubgroupSize = 32` when supported by the adapter).

## 2. Baseline Codebase Readiness Audit

Before Phase 0 expansion, the workspace (`ash 0.38`, `ash-window 0.13`, `gpu-allocator 0.28`, `spirv-builder 0.11.0`, `spirv-std 0.11.0`, `glam 0.34.1`, `rapier3d 0.36.1`, `winit 0.30.13`, Rust edition `2024`) has these completed foundations and remaining structural gaps:

### Ready Foundations
- **Private Vulkan 1.3 Baseline (`crates/engine/src/gpu/`):** `ash 0.38` + `ash-window 0.13` + `gpu-allocator 0.28` device/swapchain/dynamic-rendering/`synchronization2` renderer, `spirv-unknown-vulkan1.3` shader builds, `EngineError::Gpu` typed startup errors, declarative `RenderEffect` (`EffectShaderSpec`, zero `ash`/`unsafe` in `crates/fx_fresnel_rim`), private `UiRenderTarget::composite_rgba8`, and headless Vulkan 1.3 SPIR-V pipeline validation tests.
- **Simulation/Render Isolation (`crates/engine/src/runner.rs`, `snapshot.rs`):** `Renderer` is private and reads immutable double-buffered `RenderSnapshot<G>`. `RenderSchedule::Parallel` overlaps `Sim N+1` with `Render N`.
- **Shared ABI (`crates/shader_abi/src/lib.rs`):** `#![no_std]` crate with scalar-backed `#[repr(C)]` types (`Vec4f`, `Mat4f`) and optional `bytemuck` derives shared by `engine` and `core_shader`.
- **Contiguous Transform Storage (`crates/engine/src/physics.rs`):** `SoaStorage` maintains dense `positions`, `rotations`, and `bounds` arrays.
- **Decoupled UI (`crates/engine/src/ui.rs`):** `UiOverlay::render` runs after the 3D scene pass via `UiRenderTarget::composite_rgba8`.

### Structural Gaps Addressed by Phases 0 to 3
1. **Immediate-Mode Box Snapshot vs. Retained GPU Scene (`world.rs`, `gpu/scene_pipeline.rs`, `runner.rs`):** `collect_render_meshes` performs a hardcoded 200 m CPU octree query and clones box primitives every frame. Must transition to a retained GPU scene fed by a frame-index-fenced append-only monotonic delta queue (`delta.frame_index <= snapshot.frame_index`, accumulating mutations across `Sim` steps so `Parallel -> Sequential` overwrites and pre-`resumed` `GameApp::init` spawns never drop updates and `Sim N+1` never leaks into `Render N`) plus per-frame dynamic state (previous-frame transforms for motion vectors and `history_reset` invalidation flags).
2. **Missing Asset Registry & Upload Queue (`runner.rs`, `world.rs`):** `SimRunner::new` runs `GameApp::init` before `VulkanDevice` exists. Requires a device-independent opaque handle registry bridged to an async GPU upload queue.
3. **Strict Vulkan 1.4 Minimum Upgrade, Frame-Sync Migration & Render Graph (`gpu/device.rs`, `gpu/renderer.rs`, `gpu/scene_pipeline.rs`):** The completed baseline currently checks `API_VERSION_1_3` with `FRAMES_IN_FLIGHT = 2` and binary `vk::Fence`. Phase 0 upgrades startup to enforce **strict Vulkan 1.4 minimum** (`ApplicationInfo::api_version = 1.4.0`, `props.api_version >= 1.4.0`, rejecting any sub-1.4 or non-RT adapter), compiles engine and `fx_fresnel_rim` shaders to `spirv-unknown-vulkan1.4` (`multimodule(true)` for `core_shader`), enables exact Vulkan feature structs (Vulkan 1.0 `VkPhysicalDeviceFeatures`: `fragment_stores_and_atomics`, `shader_storage_image_extended_formats`, `depth_clamp`; `PhysicalDeviceVulkan12Features`: `timeline_semaphore`, `buffer_device_address`, `draw_indirect_count`, `scalar_block_layout`, `runtime_descriptor_array`, `descriptor_binding_partially_bound`, `descriptor_binding_sampled_image_update_after_bind`, `descriptor_binding_variable_descriptor_count`, `shader_sampled_image_array_non_uniform_indexing`; `PhysicalDeviceVulkan13Features`: `dynamic_rendering`, `synchronization2`, `subgroup_size_control`; `PhysicalDeviceRayQueryFeaturesKHR`; `PhysicalDeviceAccelerationStructureFeaturesKHR`; optional `PhysicalDeviceMeshShaderFeaturesEXT` / `PhysicalDeviceHostImageCopyFeaturesEXT`; plus `VkPhysicalDeviceSubgroupProperties` verification) and enables only the device extensions actually consumed (`VK_KHR_push_descriptor`, `VK_KHR_ray_query`, `VK_KHR_acceleration_structure`, `VK_KHR_deferred_host_operations`, `VK_EXT_memory_budget`, `VK_KHR_swapchain`, optional `VK_EXT_mesh_shader` and `VK_EXT_host_image_copy`), migrates `VulkanRenderer` to triple-buffered dynamic pools + timeline-semaphore submit-serial reclamation (`completed_timeline_value >= freed_at_submit_serial`), adds optional DMA transfer/async compute queues, `VkPipelineCache`, private transient alias `vk::DeviceMemory` heaps, and the internal Render Graph barrier tracker.
4. **Missing Rendering Domain Primitives (`physics.rs`, `snapshot.rs`, `save.rs`, `world.rs`):** Needs stable persistent `AssetId` keys vs. ephemeral runtime handles (`MeshHandle`, `MaterialHandle`, `TextureHandle`, `SkeletonHandle`, `FontHandle`), dynamic lights (`LightId` handle table / commands), highlight categories, cutout flags, dual `CameraMode` (First-Person + viewmodel vs. Isometric + cutout target), `VisualStyle`, `UpscalerBackend`, 3D MSDF signs, and `AssetId` + animation-state `ActorCheckpoint` schemas.
5. **GPU-Driven Multi-Stage `RenderEffect` Evolution (`effect.rs`, `crates/shader_abi`, `crates/fx_fresnel_rim`):** `RenderEffect` is already declarative (`EffectShaderSpec`), currently wired to CPU box vertex ranges and legacy Set 0/Set 1 constants. Phase 0/3 migrates `crates/shader_abi` to the frozen Set 0 (bindless + samplers + `FrameConstants`) / Set 1 (`pushDescriptor` per-stage transient bindings) / Push-Constant ABI and evolves `EffectShaderSpec` to typed Pass-8 (overlay vs. opaque replacement), Pass-10, and Pass-11 GPU-driven hook stages backed by per-`EffectId` indirect/mesh queues emitted by Pass 4/5 and GPU instance `EffectAttachment` parameters.
6. **Full-World `Octree::rebuild` (`physics.rs`):** Rebuilds the entire octree on every spawn, despawn, or `SetPosition`. Must separate versioned pre-baked static sector colliders from Rapier's incremental dynamic broadphase.
7. **Large-World Precision (`physics.rs`, `snapshot.rs`, `world.rs`, `save.rs`):** `rapier3d` and `glam::Vec3` use `f32`. Seamless large worlds require canonical `DVec3` across `ActorSpawnDesc`, `PhysicsCommand`, `WorldReadView`, `SpatialQuery`, `Aabb3`, `RaycastHit`, `CameraSnapshot`, `GizmoBox`, and `ActorCheckpoint`, with active-origin rebasing for `rapier3d` and camera-relative `f32` rebasing in Pass 1.

## 4. Phased Implementation Plan

### Phase 0: Vulkan 1.4 Capabilities, `rust-gpu` Multi-Module Spike, Render Graph Barriers, Timeline Sync, GPU Arenas & `shader_abi`
- **Spec Sections:** 1, 7, 8, 18.
- **Dependencies:** None (builds directly on the completed `ash` + `gpu-allocator` baseline).
- **Deliverables:**
  1. **Pure `rust-gpu 0.11.0` Vulkan 1.4 Multi-Module Capability Spike (`crates/engine/build.rs`, `crates/engine/shaders/core_shader`, `crates/fx_fresnel_rim/build.rs`):**
     - Migrate `crates/engine/build.rs` and `crates/fx_fresnel_rim/build.rs` to `spirv-unknown-vulkan1.4`. Configure `core_shader` with `SpirvBuilder::multimodule(true)` and `env_shader_spv_path = None/false` (required by `spirv-builder 0.11.0`), generating an `OUT_DIR` Rust manifest from `result.module.unwrap_multi()` so each entry point emits an isolated `.spv` file and optional `TaskEXT`/`MeshEXT` modules (`OpCapability MeshShadingEXT`) never pollute non-mesh fallback modules (fall back to a sibling `core_shader_mesh` crate if `spirv-builder 0.11.0` leaks module-wide capabilities).
     - Verify pure `rust-gpu` compilation and direct `vkCreateShaderModule` / pipeline creation on real Vulkan 1.4 RT hardware with `VK_LAYER_KHRONOS_validation` for: wave-size-agnostic subgroups (`#[spirv(subgroup_size)]`, 128-bit `SubgroupMask`, ballot/shuffle/scan) + opt-in Wave32 `subgroupSizeControl` hint, unsized `spirv_std::RuntimeArray<Image!(...)>` `NonUniform` bindless sampling (`UPDATE_AFTER_BIND` + `VARIABLE_DESCRIPTOR_COUNT`, in both fragment and compute stages), Set-1 `pushDescriptor` storage buffers + 128 B push constants (`#[spirv(push_constant)]`), `RayQuery` (including non-opaque candidate-intersection alpha-test traversal), `#[spirv(early_fragment_tests)]` + fragment storage buffer writes (`fragmentStoresAndAtomics`), `#[spirv(invariant)]`, `shaderStorageImageExtendedFormats`, and isolated `TaskEXT`/`MeshEXT` mesh shaders.
  2. **Strict Vulkan 1.4 Device Enablement, `VK_EXT_memory_budget` Clamping, Format Probing & Dynamic Presets (`crates/engine/src/gpu/device.rs`, `config.rs`):**
     - Set `ApplicationInfo::api_version = vk::make_api_version(0, 1, 4, 0)` and enforce **strict Vulkan 1.4 RT minimum** (`props.api_version >= vk::make_api_version(0, 1, 4, 0)`, rejecting any adapter below Vulkan 1.4 or missing RT with `EngineError::Gpu(GpuError::UnsupportedAdapter)`) in both `new_windowed()` and single mandatory-RT `new_headless()` (zero sub-1.4 or software-rasterizer fallback). Enable exact Vulkan feature structs: Vulkan 1.0 `VkPhysicalDeviceFeatures` (`fragment_stores_and_atomics`, `shader_storage_image_extended_formats`, `depth_clamp`), `PhysicalDeviceVulkan12Features` (`timeline_semaphore`, `buffer_device_address` for host-side AS builds, `draw_indirect_count`, `scalar_block_layout`, `runtime_descriptor_array`, `descriptor_binding_partially_bound`, `descriptor_binding_sampled_image_update_after_bind`, `descriptor_binding_variable_descriptor_count`, `shader_sampled_image_array_non_uniform_indexing`), `PhysicalDeviceVulkan13Features` (`dynamic_rendering`, `synchronization2`, `subgroup_size_control`), `PhysicalDeviceRayQueryFeaturesKHR` (`ray_query`), `PhysicalDeviceAccelerationStructureFeaturesKHR` (`acceleration_structure`), optional `PhysicalDeviceMeshShaderFeaturesEXT` (`task_shader`, `mesh_shader`), optional `PhysicalDeviceHostImageCopyFeaturesEXT` (`host_image_copy`), and verify `VkPhysicalDeviceSubgroupProperties` (`BASIC | BALLOT | ARITHMETIC | SHUFFLE`) and `maxPushConstantsSize >= 128 B`. Explicitly enable required device extensions in `vkCreateDevice::ppEnabledExtensionNames` (`VK_KHR_push_descriptor`, `VK_KHR_ray_query`, `VK_KHR_acceleration_structure`, `VK_KHR_deferred_host_operations`, `VK_EXT_memory_budget`, plus `VK_KHR_swapchain` when windowed, and optional `VK_EXT_mesh_shader` and `VK_EXT_host_image_copy` when supported; omit unused `maintenance5`/`maintenance6`/`dynamic_rendering_local_read`), plus optional dedicated DMA transfer + async compute queue families.
     - Probe `vkGetPhysicalDeviceFormatProperties` at startup for `VK_FORMAT_R16G16_SNORM` (`COLOR_ATTACHMENT_BIT`, falling back to `R16G16_SFLOAT`) and `VK_FORMAT_B10G11R11_UFLOAT_PACK32` (`STORAGE_IMAGE_BIT`, falling back to `R32_UINT` bit-packed or `R16G16B16A16_SFLOAT`). Return typed `EngineError::Gpu(GpuError::UnsupportedAdapter)` when Vulkan 1.4 or required ray-query/descriptor-indexing features are missing.
     - Auto-select runtime preset (`Radeon780M` at 30 FPS floor, `Radeon890M` at 60 FPS `720p` internal / `0.5x` ReSTIR, `DiscreteDesktop` at 60+ FPS native with `0.75x` ReSTIR/GI and `0.5x` Reflections defaults + `1.0x` Quality toggle, `HighEnd4K` at 90+ FPS) applying deterministic `VK_EXT_memory_budget` clamping (`<= 75%` of available `DEVICE_LOCAL` heap budget: reserve fixed targets/pools + `BLAS_POOL_BUDGET_MB` first, then split remaining headroom `25%` `STATIC_GEOMETRY_ARENA_MB` / `75%` `TEXTURE_STREAM_BUDGET_MB` capped at tier ceilings); expose `VisualStyle` (`Realistic` | `Comic`) and `UpscalerBackend` (`TaauRcas`).
  3. **Frame-Sync Migration, Render Graph Barrier Tracker, Transient Alias Heaps, `VkPipelineCache`, Memory Pools, Static Geometry Arena & Exact-Budget `BlasPool` (`crates/engine/src/gpu/`):**
     - Migrate `VulkanRenderer` (`gpu/renderer.rs`, `gpu/scene_pipeline.rs`) from `FRAMES_IN_FLIGHT = 2` + binary `vk::Fence` to triple-buffered dynamic pools + timeline-semaphore submit serials, driving deferred arena/BLAS/texture reclamation strictly from `completed_timeline_value >= freed_at_submit_serial`.
     - Implement lightweight internal Render Graph state tracker emitting minimal `vkCmdPipelineBarrier2` layout/access transitions per pass (supporting Pass 2b and Pass 3 async-compute overlap with Pass 4/5), binding per-pass transient resources via Set-1 `pushDescriptor`, and implementing two private raw `vk::DeviceMemory` transient alias heaps (one optimal-image heap with `VK_IMAGE_CREATE_ALIAS_BIT` and `UNDEFINED` layout barriers, one linear-buffer heap honoring `bufferImageGranularity` and `memoryTypeBits`, since `gpu-allocator 0.28` does not expose aliasing).
     - Implement on-disk `VkPipelineCache` load/save, triple-buffered dynamic pools, TLSF/free-list sub-allocated static geometry arena (retaining flat BLAS triangle-index slices + vertex tangent frames alongside meshlet buffers), exact-budget `BlasPool` sub-allocated inside a fixed `VK_BUFFER_USAGE_ACCELERATION_STRUCTURE_STORAGE_BIT_KHR` arena + scratch buffer (`vkGetAccelerationStructureBuildSizesKHR` + `VK_QUERY_TYPE_ACCELERATION_STRUCTURE_COMPACTED_SIZE_KHR`), fixed Pass 1 upload staging ring (`STAGING_RING_MB`, DMA transfer queue capable + optional `hostImageCopy` fast path for small mip tails / UI RGBA8), and triple-buffered host-mapped mipmap-feedback readback ring.
  4. **Shared ABI & Descriptor Set Layout Freeze (`crates/shader_abi/src/lib.rs`, Scalar-Backed `#[repr(C)]` Only) & Phase 1 Dependency Smoke Check:**
     - Keep `crates/shader_abi` free of `glam` dependencies using scalar-backed `#[repr(C)]` types (`Vec4f`, `Mat4f`, `[f32; 4]`). Freeze canonical Descriptor Set indices (`SET_BINDLESS_GLOBAL = 0`: `binding 0` `RuntimeArray` sampled images, `binding 1` immutable samplers, `binding 2` `FrameConstants` UBO; `SET_PASS_TRANSIENT = 1` `pushDescriptor` per-stage binding table for Pass 8/10/11 hooks) and `PushConstants` (`<= 128 B`, counts/pool discriminators/element offsets/active `EffectId`). Define `FrameConstants` (including `world_view_proj`, `inv_world_proj`, `viewmodel_view_proj`, `inv_viewmodel_proj`, `prev_viewmodel_view_proj`, viewport depth-partition constants), `GpuLight` (`48 B`: `position_range`, `color_source_radius`, `dir_and_packed_cones`), `ClusterHeader` (`8 B`), `MeshletDesc`, `GpuVertex` (`48 B`: position, normal, tangent, uv), `GpuSubmeshDesc` (mapping `(instance_custom_index, geometry_index)` to static/dynamic storage-buffer pool discriminator + vertex/index element offsets and `MaterialId` for Pass 7 ray-hit shading), `GpuInstance` (including `EffectAttachment` parameters and submesh range), `GpuMaterial`, `HighlightCategory`, and compressed bone transform structs.
     - Verify pure-Rust transitive dependency trees and exact APIs for Phase 1 `crates/asset_pipeline` crates (`meshoptimizer-rs`, `block_compression` `bc15`/`bc7` `compress_rgba8`, `fdsm`, `fdsm-ttf-parser`, `ktx2`, `gltf`) before starting Phase 1.
- **Verification Gate (CPU Unit Suite + Real Vulkan 1.4 RT Hardware with `VK_LAYER_KHRONOS_validation`):**
  - `cargo clippy --workspace --all-targets -- -D warnings`.
  - Default `cargo test --workspace` passes all CPU unit tests (zero GPU dependency: `shader_abi` byte-size/alignment tests, preset/`VK_EXT_memory_budget` clamping split, arena/pool/timeline-serial/barrier-tracker unit tests).
  - Hardware Vulkan 1.4 RT validation suite (`#[ignore]` hardware tests executed on real Vulkan 1.4 RT hardware via `cargo test --workspace -- --ignored` with `VK_LAYER_KHRONOS_validation`): strict Vulkan 1.4 RT `new_headless()` probing, `RuntimeArray` `UPDATE_AFTER_BIND` + Set-1 `pushDescriptor`, push constants, wave-portable subgroups + Wave32 `subgroupSizeControl`, `#[spirv(early_fragment_tests)]` + `fragmentStoresAndAtomics`, `#[spirv(invariant)]`, `VK_KHR_ray_query`, isolated `VK_EXT_mesh_shader` `.spv` modules, optional `hostImageCopy`, private transient alias heap barriers, and `shaderStorageImageExtendedFormats` compute storage writes.

### Phase 1: Offline Asset Pipeline (`crates/asset_pipeline`) & Async Streaming Runtime
- **Spec Sections:** 10, 11, 15, 18.
- **Dependencies:** Phase 0 (`shader_abi`, GPU arenas, staging/readback rings, `UPDATE_AFTER_BIND` descriptor set).
- **Deliverables:**
  1. **Offline Asset Compiler (`crates/asset_pipeline`, 100% Pure Rust, Zero C/C++ Build Dependencies):**
     - Ingest glTF 2.0 via pure-Rust `gltf` (meshes + MikkTSpace tangents, PBR materials, alpha-test flags, skeletons, animations, scene transforms).
     - Generate 64-vertex / 124-triangle meshlets with bounding spheres and backface cones, 4 to 6 automatic LOD levels (`build_lod_chain` and skinned `simplify_character`), and merged per-sector HLOD proxies via pure-Rust `meshoptimizer-rs` (v0.2+, zero C++ toolchain).
     - Compress albedo/ORM textures to BC7 and normal maps to BC5 via pure-Rust CPU `block_compression` (`default-features = false, features = ["bc15", "bc7"]`), padding `2x2` and `1x1` mip tails to `4x4` blocks as required by `compress_rgba8`, parallelized via `rayon` with content-hash caching, and written by a custom pure-Rust KTX2 v2.0 container writer inside `crates/asset_pipeline` emitting **uncompressed** (`supercompressionScheme = 0`) BC7/BC5 mip pyramids validated with the read-only `ktx2` crate (zero runtime CPU decompression on `mmap` upload).
     - Generate MSDF font atlases and glyph metric tables via pure-Rust `fdsm` + `fdsm-ttf-parser` (zero C++ `msdfgen`).
     - Pre-bake versioned serialized `rapier3d` static collider chunks (`rapier_schema_version` + raw triangle-soup/convex fallback) separating Tier-0 ground/walkmesh colliders from detailed prop colliders.
     - Emit sector containers and a reference-counted shared asset manifest keyed by stable persistent `AssetId` identifiers.
  2. **Runtime Memory-Mapped Store & Private OS I/O Pool (`crates/engine/src/assets/mmap_store.rs`, `io_pool.rs`):**
     - Isolate `#[allow(unsafe_code)]` for read-only `mmap` inside `assets/mmap_store.rs`.
     - Run all `mmap` page reads, KTX2 mip reads, and collider deserialization on a private OS I/O thread pool (zero I/O in `TaskSlab` or render thread) with instant stale-request cancellation and lock-free handoff compatible with `RenderSchedule::Parallel`.
  3. **Device-Independent Handle Registry & Independent Residency Coordinators (`crates/engine/src/assets/`):**
